### D. 账号数据与云快照（v118 · 本次重点）

```
用户上传故事书 ──► data/eu-public/mall/resources/*.json
个人云快照     ──► data/<handle>/eu-mall-browser-state.json（仅索引/资料，无书库正文）
AI 对话        ──► 同上文件内三键 + POST/GET .../conversations
贴吧           ──► data/eu-tieba-board.json
```

- 上线后用户**首次登录并保存/同步**时，服务端会自动 **purge** 旧 `eu_demo_dev_heavy` 等键（若曾 100MB+，建议上线前本机先备份再删 heavy，见 `034`）。
- **勿**用本机 `data/<handle>/` 整包覆盖线上用户目录。

### E. 酒馆 index 稳定性

- 勿再改 `script.js` 发送大链（`031` 已回退）。
- Token 红条：xAI 兜底在 `tokenizers.js`（`002`）。

### 4.2 仅 SFTP（不进 Git）

| 场景 | 操作 |
|------|------|
| 线上**已有** 626 本商城 | **不必**重传 `data/eu-public/mall/` |
| 线上**空库** | 只上传 `data/eu-public/mall/`（resources + thumbs）→ `node tools/eu-mall-rebuild-index.mjs` |
| 线上用户 browser-state 过大 | **不要**覆盖；让用户用 v118 登录后自动 purge，或运维删 `eu_demo_dev_heavy` 后重启 |

### 4.3 改代码后是否重启 Node

| 改动 | 浏览器 | Node |
|------|--------|------|
| 仅 `public/eu.html` | **Ctrl+F5** | 可不重启 |
| `src/endpoints/eu-*.js` | Ctrl+F5 | **必须重启** |

**本次 v118 含 `eu-browser-state.js` + `eu-mall-resources.js` → 上线必须 kill 旧 node 再启。**

## 八、踩坑速查

| 现象 | 处理 |
|------|------|
| 线上仍是 v117 | 未 pull / 未硬刷新 / node 未重启 |
| `contribute` 404 | 未部署 `eu-mall-resources.js` 或未重启 node |
| 登录极慢 / settings 超时 | 查 `data/<handle>/eu-mall-browser-state.json` 是否仍 >10MB；删 heavy 或等 v118 purge |

| 用本机 data 覆盖线上 | **禁止**整包 `data/`；仅 `eu-public/mall` |
