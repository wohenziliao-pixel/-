## 4. 和「工作目录 / 运行目录里另存一份单机构件」的关系

- **本仓库在 Cursor 里只打开一套工作区**时，日常开发**始终改的是当前工作区里的那一份**（例如本路径下的 `public/eu-demo.html`）。
- **另存**「单机稳定版」**工作目录 / 运行目录各一份」**属于你在资源管理器或发布脚本里做的**文件级复制或压缩**；**不在本仓自动多拷一份**除非你本地已执行过。
- 若需**第二次冻结**：建议在复制出的目录**单独**再打标签或只读备份，与「还在开发的主仓库」分开。
