# 幽灵故事书一键清理

## 任务目标

清理商城/开发者列表中“只有图片展示、无有效故事内容”的幽灵故事书，避免逐条手动删除。

## 做了什么

- 在开发者列表批量操作区新增按钮：`清理幽灵故事书`。
- 新增识别规则 `isGhostStorybookItem`，用于匹配：
  - 类型为故事书；
  - 有封面图；
  - 无 entries / catalog / regex 等有效内容结构；
  - `desc` 与 `first_mes` 呈“PNG 导入无嵌入 JSON / 占位描述”特征；
  - `raw` 结构较薄（通常是占位导入对象）。
- 新增执行函数 `cleanupGhostStorybooks`：
  - 一次性确认；
  - 复用硬删除链路（会话、localStorage、列表、侧栏、状态同步）；
  - 删除完成显示成功/失败统计。

## 改动路径

- `public/eu-demo.html`

## 用户自测建议

1. 在开发者页点击 `清理幽灵故事书`，确认后应批量删除这类占位故事书。
2. 清理后检查商城故事书列表与我的世界侧栏，不应再出现这些幽灵项。
3. 若某条仍保留，通常说明其含有效内容结构（非幽灵），可按常规勾选删除处理。
