# 灌水开发者删帖：始终附带 euTiebaDev 标记

## 问题

开发者模式下批量/单帖删帖仍 403。原因：`euTiebaDeleteBody` / `euTiebaDevDeleteQuerySuffix` 仅在 `!euTiebaSessionCache.canModerate` 时附加 `euTiebaDev`；若客户端误判为版主（缓存或接口不一致），请求不带开发者标记，服务端拒绝。

## 改动

- `public/eu-demo.html`：开发者模式且已登录时**始终**在删帖 URL 与 JSON 体附带 `euTiebaDev`（版主时服务端仍走 `canModerate`）；构建戳 `20260512-068`。
- `src/endpoints/eu-tieba.js`：`readEuTiebaDevClientFlag` 对 JSON 体 `euTiebaDev` 同时接受 `true` / `1` / 字符串 `true|yes|1`。
