# 侧栏故事书缩略图兜底修复

## 任务目标

修复刷新后「我的世界」左侧故事书会话缩略图消失的问题，保证即使图片字段缺失、损坏或被存储配额降级，也能有可见头像。

## 做了什么

- `getConversationAvatarHtml` 增强图片来源兜底：按 `img/cover/image/avatar/thumbnail/icon` 顺序取图，不再只看 `img`。
- 给头像图片加 `onerror` 回退：图片加载失败时改为显示 `📖`，避免空白圆点。
- 书类无图时默认显示 `📖`（而不是可能不明显的首字）。
- 新增 `buildTinyCoverDataUrl`：当触发 localStorage 配额降级时，为超大图替换为小型 SVG data URL 缩略封面，而不是直接置空。
- `persistDevItems` 的配额降级分支从 `img: null` 改为 `img: buildTinyCoverDataUrl(x)`，刷新后仍有封面占位。

## 改动路径

- `public/eu-demo.html`

## 用户自测建议

1. 刷新页面后，左侧「我的世界」故事书会话应出现缩略头像（真实图或兜底图标），不再空白。
2. 若导入超大封面触发配额提示，再刷新也应看到 SVG 小封面兜底。
3. 故意把某条 `img` 改成无效 URL，侧栏头像应自动回退为 `📖`。
