# 故事书删除被云同步合并拉回

## 任务

用户反馈《欧阳见》等故事书「死活删不掉」：侧栏 × 无效或删后刷新/登录又出现。

## 根因

1. **侧栏 ×** 只删「我的世界」里的一条**会话**，不从故事书库移除；会话 key 与 `characterSessions` 不一致时还会提示「未找到可删除的会话」。
2. **故事书库删除** 虽会 `persistAcquiredSet`，但登录/同步时 `euMergeAcquiredUidJsonStrings` 对本地与云端做**并集**，服务器旧列表会把已删 uid 合并回来。
3. **`euPinnedAcquiredRows`** 未在删除时清理，仅靠 pinned 也会继续出现在故事书列表。

## 改动

- `public/eu.html`
  - 新增 `eu_demo_acquired_gen_<handle>` 版本号；`persistAcquiredSet` 自增；合并时**高版本整表覆盖**（删除以本地为准）。
  - 删除后 `euPushAcquiredStateAfterUserDelete()` 立即上传 browser-state。
  - `euUnpinAcquiredRow`；`removeMallItemFromMyWorld` / `euDeleteStorybookFromLibrary` 路径清理 pinned。
  - 会话删除：按 `characterName` 回退匹配 `conversationStore` 单条。
  - 侧栏删会话成功时提示：要从库删除请到故事书页卡片垃圾桶。
  - 构建戳：`20260519-storybook-delete-sync-v85`

## 自测

1. 故事书页 → 卡片右下角垃圾桶 → 确认 → 刷新后该书不在列表。
2. 登录/换页后不应再出现（需已部署且云端 push 成功）。
3. 侧栏 × 仅删会话；库删除用故事书页垃圾桶。

## 部署

更新 `public/eu.html` 并强刷（`?v=` 或清缓存）。
