# 顶栏登录区恢复为账号 + 三选项下拉

## 任务

右上恢复旧版式：**只显示登录账号**与**下拉三项**（个人资料 / 切换账号 / 退出登录）；个人资料与左下角头像一致；切换账号与退出均回到登录页。

## 做了什么

- **顶栏按钮**：去掉顶栏小头像，仅 **账号名 + 下拉箭头**；`syncTopbarLoginAccountLabel()` 只写 `state.currentUser`；左下角仍用 `syncEuSidebarDisplayName()`（昵称优先）。
- **CSS**：补全误删选择器的 `.user-drop-arrow`，避免后续规则解析异常。
- **菜单交互**：`closeTopbarUserMenu()`；三项用 `href="#"` + `preventDefault`；个人资料先关菜单再 `openAccountProfilePage()`。
- **登录页**：`showEuLoginPageLayout()` 统一去掉各 `.page` 的 `active`、显示 `#page-login`（清除 `display:none`）、隐藏 `#app-layout`；`doLogout` 清空表单；`switchToLoginPage` 预填刚退出的账号便于重登。
- **移除**未再使用的 `switchTab`。

## 改动路径

- `public/eu-demo.html`

## 自测

1. 登录后顶栏右侧为 **handle** + 箭头，点开为三个链接。  
2. 个人资料进入与侧栏点头像一致。  
3. 切换账号 / 退出后均出现登录页；切换账号时用户名输入框预填原账号。
