# 连接配置：先 API/密钥连通，再填模型

## 问题

用户理解：须先保证 **API 来源 + 密钥连通**，模型下拉才有效；切换配置时若预填模型，连接拉取列表时会用旧 slug（如 GLM 覆盖 Euryale）。

## 改动

`connection-manager/index.js` 切换配置改为三阶段：

1. **阶段 1**：重置并填入来源、密钥、Custom URL 等（**不含**任何 `*_model` 与 OpenRouter 提供商/量化）。
2. **阶段 2**：`reconnectOpenAi()`，等待状态 **有效**。
3. **阶段 3**：连通成功后再写入 `profile.model` / 快照中的模型及 OpenRouter 附属项。

连通前将 `oai_settings` 中模型字段恢复默认，避免 `saveModelList` 使用错误模型。

**保存**：仅当 `online_status !== 'no_connection'` 时把模型写入 `connectionSnapshot` 与 `profile.model`（须先连接或点连接成功后再「更新配置」）。

## 用户操作

1. 硬刷新。
2. 选中配置 → 设第三项来源 → **先点连接至有效** → 再选模型 → **更新配置**。
3. 切换其它配置再切回，应先连通再出现正确模型。
