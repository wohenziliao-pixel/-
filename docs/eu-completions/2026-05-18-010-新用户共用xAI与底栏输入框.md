# 新用户共用 xAI 与底栏输入框

## 任务
1. 新注册用户仍报 `OpenAI API key is missing`，应自动套用站长 `wohenziliao` 的 xAI 配置。
2. 移动端底栏去掉「重新生成 ↻」与「发送 ▶」两个按钮，加宽对话输入框。

## 做了什么

### 共用 API（服务端）
- 加强 `src/endpoints/eu-shared-api.js`：
  - 目标无 `settings.json` 时整份复制站长配置；
  - 复制预设后把 `OpenAI Settings/*.json` 里残留的 `chat_completion_source: openai` 改为 `xai` 并补 `xai_model`；
  - 若存在 `api_key_xai`，强制 `oai_settings.chat_completion_source = xai`。
- 新增已登录接口 `POST /api/eu/shared-api/sync`（`server-main.js` 挂在 `requireLogin` 之后）。

### 共用 API（前端）
- `eu.html`：登录 `enterApp` 时调用 `euSyncSharedApiFromServer()`，修复已注册但未套用的账号（如 `ziliaowohenni`）。
- 解析 settings 时：若全局/合并后仍为 `openai` 但已有 `xai_model`，按 `xai` 走。

### 底栏 UI
- 移除 `#world-regen-btn`、`.send-btn`（重新生成/发送仍在 ☰ 菜单与 Enter 发送）。
- 输入框 `flex: 1` 占满剩余宽度，占位符提示 Enter 发送。

## 改动路径
- `src/endpoints/eu-shared-api.js`
- `src/server-main.js`
- `public/eu.html`

## 热修（线上 500）
- 若启动报 `Named export 'writeFileAtomicSync' not found`，将 `eu-shared-api.js` 第 9 行改为：
  `import { sync as writeFileAtomicSync } from 'write-file-atomic';`（与 `settings.js` 等一致）

## 部署与自测
1. 本机 `git push` 后服务器 `git pull`，重启 node。
2. `config.yaml` 确认 `euSharedApiFromHandle: wohenziliao`。
3. 用问题账号重新登录一次（会触发 sync），再发消息，不应再出现 OpenAI key 报错。
4. 或新注册测试账号验证。
5. 手机底栏：仅 ☰、续写 ➤、💡 + 宽输入框；Enter 可发送。
