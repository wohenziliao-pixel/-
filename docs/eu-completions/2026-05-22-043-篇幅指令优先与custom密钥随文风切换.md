# 篇幅指令优先与 custom 密钥随文风切换

## 任务

1. 排除自动续写前提下，说明 700–1000 字未严格遵守的原因。  
2. 温柔风/创意风连接仍失败，查根因并修复。

## 结论（给用户）

### 700–1000 字

- **命令有注入**（`euWritingStyleAgent`），不是没执行。  
- **不保证字数**：`max_tokens=2048` 只限制上限；模型可提前 `stop`。  
- **世界书/用户规则** 在 system 栈里与铁律并存，会稀释注意力（非自动续写块）。  
- **改法**：铁律与「篇幅硬指标」改到 **user 轮之前最后两条 system**；并保留世界书在前的设定摘录。

### 温柔风 / 创意风

- 根因：酒馆 **Custom API 全局只有一条「当前激活」密钥**；EU 切文风只改 URL/模型，**未切换** `GLM5.1` / `VENICE` 各自绑定的 `secret-id`。  
- 表现：Venice 地址 + 智谱 Key → Bad Request / 对话服务不可用。  
- **改法**：发消息前 `POST /api/secrets/rotate` 激活对应 profile 的密钥；切换文风时同样 rotate。

### 手机偶发「写到一半又变」

- 在关闭自动续写时，多为：流式结束后 **去重/清洗换气泡**，或 **流式失败走非流式兜底**（非第二次续写）。
