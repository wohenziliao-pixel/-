# 2026-05-01-017 移除会话不删整夹聊天目录

## 问题
- 用户仅「移除对话」时，体感故事书/商城品类或酒馆侧数据被连带删掉。

## 根因
- `POST /api/extensions/eu-runtime-hook` 在 `stage === 'deleteConversationFiles'` 时，对 `characterName` 与 `storybookTitle` 对应的 **整个 `chats/<文件夹>`** 执行 `fs.rmSync(..., { recursive: true })`。
- EU 会话的 `storybookTitle` 常与酒馆角色目录名相同，递归删除会清掉该目录下 **全部** 聊天与相关文件，远超「删一条会话」语义。

## 改动
- `src/endpoints/extensions.js`
  - 默认：仅按 `conversations[].characterName` + `chatFile` 删除对应 `.jsonl` 文件。
  - 仅当 `payload.deleteEntireCharacterFolders === true` 时保留原「整夹删除」行为（供开发者硬删资源）。
- `public/eu-demo.html`
  - `hardDeleteResourceFromSystem` 调用 `deleteConversationFiles` 时传入 `deleteEntireCharacterFolders: true`。
  - 用户 `doDelete` / 普通「移出我的世界」不传该字段，走文件级删除。

## 自测
1. 用户侧移除会话：酒馆 `chats` 下对应角色目录应仍在，仅删除与 `chatFile` 匹配的文件（若 EU 提供了 `chatFile`）。
2. 开发者页硬删故事书：仍可整夹清理（需传 `deleteEntireCharacterFolders`）。
