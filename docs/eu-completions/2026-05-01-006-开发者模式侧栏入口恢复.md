# 任务目标

- 在不处理红条逻辑的前提下，实现其余开发者模式需求：
  - 开发者模式切页不自动退出；
  - 左侧用户区上方显示“开发者模式启动中”入口；
  - 普通用户页面保持不变，仅多一个开发者入口和开发者页面。

# 实施内容

1. 在 `public/eu-demo.html` 恢复侧边栏开发者入口：
   - 新增按钮 `#dev-mode-entry`，位置在左侧 `sidebar-footer` 用户信息上方；
   - 点击后调用 `showDevMode()` 进入开发者页面。

2. 恢复侧栏入口样式：
   - 新增 `.dev-mode-entry` / `.dev-mode-entry.active` 样式，用于开发者模式激活时显示该入口。

3. 将开发者模式可见性绑定到状态机：
   - `updateDevModeUi()` 依据 `state.devModeEnabled` 控制 `#dev-mode-entry` 显示；
   - 维持此前“切页不自动退出开发者模式”的行为（不新增自动退出逻辑）。
