# 重开浏览器后对话记录丢失（v97）

## 任务

用户反馈：昨晚起修的「关浏览器再开聊天记录要还在」仍不生效；已部署 v96，push ok，但重开后对话/历史未保留。

## 根因（与本地酒馆无关）

线上 `https://st.ciyuanji.shop` 只依赖：

1. 本机 `localStorage` 三键（同账号同站点一般会保留）
2. 服务器 `data/<handle>/eu-mall-browser-state.json` 对话快照

重开丢失的常见链路：

1. **云端仍是「已清理」锁**（`resume.clearedAt` + 空 `conversations`）→ 登录 pull 把本机也清空；或 push 被拒写，关页后只剩空云端。
2. **专用 GET `/conversations` 未含 conv 键时**误走整包 `browser-state`，大文件解析漏键 → 当成云端空。
3. **`loadConversationRuntime` 末尾 `persistConversationRuntime`** 在内存尚未灌入时可能触发「空 store + clearedAt」擦本机。
4. **登录后商城同步二次 merge** 在 `cleared` 时再次 `loadConversationRuntime`，覆盖刚拉下的本机对话。

## 修复（v97）

- 拉取：始终先用专用 `/conversations`；仅缺键时再补整包中的对话键。
- 合并：云端有非空对话时写入本机并**去掉 resume 的 clearedAt**；无 resume 则 `euEnsureResume…` 补全。
- 加载：`euEnterAppLoadSessionState` 内 `loadConversationRuntime({ skipPersist: true })`，避免加载后误擦。
- 登录商城同步：`cleared` 但本机仍有新会话时不 reload 清空；`merge===true` 时再 `scheduleEuResumeLastChatIfAny`。
- 构建戳：`20260520-conversation-cloud-reopen-restore-v97`。

服务器 `git pull` + 重启 Node；浏览器 Ctrl+F5 见 `reopen-restore-v97`。
