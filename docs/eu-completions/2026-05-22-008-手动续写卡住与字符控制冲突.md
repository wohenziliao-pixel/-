# 手动续写卡住（三点不动 / 无下文）

## 任务

用户点击「续写」后能看到三点，但长时间无新正文；Console 有 `[EU] continue: click`，构建戳 v107。

## 根因

1. **字符控制与手动续写冲突**：故事书开启「自动续写 / 目标 token」时，请求仍注入「本条 assistant 须在 N token 内」的 system；当前气泡已很长时，模型常返回空或极短，合并后无新增。
2. **上下文挤爆**：把整段最后一条 assistant 再塞进 history，长对话下 `selectHistoryWithinContextBudget` 可能裁掉待续写正文，只剩续写指令。
3. **max_tokens 被收紧**：手动续写仍走 `euApplyAutoContinueMaxTokens`，输出上限过小。
4. **流式 UI**：`paint()` 在 rAF 未执行时丢弃后续 delta，首包晚到时体感像卡住。

## 做了什么

- 新增 `euBuildManualContinuePrompt`：结尾摘录进 user 轮；history 仅用 `historyBefore`（不再重复整段 assistant）。
- `manualContinue: true`：跳过字符控制 system、不用自动续写 max_tokens 收紧，使用预设 `max_tokens`（至少 1024）。
- 续写超时 90s；合并后长度未增长则气泡提示「无有效新增」。
- 修复流式 `paint` 防抖；构建戳 `20260522-manual-continue-fix-v108`。

## 改动路径

- `public/eu.html`

## 自测

1. Ctrl+Shift+R，`document.documentElement.dataset.euClientBuild` → `20260522-manual-continue-fix-v108`。
2. 长对话点续写：三点后应出现流式增长；Console 有 `continue: request` / `chunk` / `done`。
3. Network 有 `chat-completions/generate` 且响应体持续增长。
4. 若仍慢：Console 有 `browser-state large` 时可在 `eu-localstorage-port.html` 清理过大 browser-state 后再试。
