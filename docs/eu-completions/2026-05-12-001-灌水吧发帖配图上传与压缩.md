# 灌水吧发帖配图上传与压缩

## 任务

用户发帖/回帖支持插入图片；上传后在服务端按常见网页大图规格压缩（长边约 1600px、JPEG），列表缩略图与详情展示使用压缩后的文件。

## 改动

- `src/endpoints/eu-tieba.js`：新增 `POST /api/eu/tieba/upload-image`（需酒馆登录），Jimp 解码、长边限制 1600、JPEG 质量 82，写入 `userImages/eu-tieba/`；拒绝 GIF、超大 Base64/像素。
- `public/eu-demo.html`：发帖弹窗与回复区「插入图片」；`euTiebaDownscaleDataUrlIfLarge`（浏览器侧长边 2400 预压）+ `euTiebaUploadTiebaForumImage` + 光标处插入 `![](/user/images/...)`；`euTiebaRichContentToHtml` 将合法 `![](url)` 渲染为 `<img>`；样式 `.tieba-content-img`。`EU_CLIENT_BUILD_STAMP`：`20260510-056`（以文件内为准）。

## 自测

登录后灌水吧发帖 →「插入图片」→ 发布后详情应显示图；列表首图缩略图应来自首楼 `![](...)`。重启 Node 后再测上传接口。
