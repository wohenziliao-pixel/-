# 用户可见错误脱敏（隐藏 EU 参数配置）

## 任务

文风/API 报错时会向用户展示具体模型名、连接名、地址等，存在被复制抄袭风险。要求底层统一处理：**任何情况下**终端用户不可看到 EU 具体参数配置。

## 实现

### `public/eu.html`（`20260522-user-error-sanitize-v122`）

1. **`euSanitizeUserFacingText` / `euCreateUserFacingError` / `euTextLooksLikeEuConfigLeak`**  
   - 识别模型、URL、Connection Manager、酒馆连接名、JSON 上游错误等敏感片段。  
   - 映射为固定短句（文风不可用、对话服务异常、超时、登录异常等）。  
   - 技术细节仅 `console.warn('[EU] user-facing (sanitized)', …)`。

2. **`formatEuUserFacingSendFailure`**：聊天气泡/发送失败统一走脱敏。

3. **`euShowGenerationErrorInBubble`**：重生成/续写失败同样脱敏。

4. **`validateEuWritingStyleGenerationRoute` / `assertValidXaiModelOrThrow`**：对内 `euInternalDetail`，对用户仅通用文风/服务提示。

5. **`showToast`**：若文案含配置泄露特征或「发送失败：」，自动脱敏后再展示。

6. **UI 文案**：文风弹窗说明去掉「切换 API」描述；开发者模式仍可通过 `euCanShowWritingStyleApiDetails()` 看 API（仅 dev）。

1. 强刷后 build 为 `v122`。  
2. 故意用错误文风配置发消息 → 气泡/Toast 仅见「当前文风暂时不可用…」或「对话服务暂时不可用…」，**不出现**模型名、URL、GLM5.1、VENICE 等。  
3. F12 Console 可见 `internal:` 完整原因供运维排查。
