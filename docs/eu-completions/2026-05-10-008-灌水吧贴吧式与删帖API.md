# 灌水吧贴吧式与删帖 API

## 任务目标

将「灌水交流区」改为贴吧式交互：主题列表、帖子详情与楼层回复；发帖/回帖与酒馆登录账号一致（服务端校验会话）；管理员可删整帖或删单层（酒馆 `profile.admin` 或 EU 管理句柄与前端 `EU_MANAGEMENT_USERS` 对齐）。

## 实现说明

- 新增 `src/endpoints/eu-tieba.js`：`GET /session`、`GET /threads`、`GET /thread/:id`、`POST /thread`、`POST /reply`、`DELETE /thread/:id`、`DELETE /reply`（删帖需 moderating 权限）。持久化文件：`{DATA_ROOT}/eu-tieba-board.json`。
- `src/server-main.js`：在 `requireLoginMiddleware` 之前挂载 `app.use('/api/eu/tieba', euTiebaRouter)`，读列表可不登录，写接口在路由内校验 `request.user`。
- `public/eu-demo.html`：重做 `#page-chatroom`（列表 + 详情双视图）、发帖弹窗、与 API 对接的脚本；抽取 `stApiRequest` 供 DELETE 使用；侧栏文案仍为「灌水交流区」，页内标题为「灌水吧」。客户端构建戳更新为 `20260510-053`。

## 用户自测建议

1. 用普通账号登录后发帖、回帖；另一浏览器/账号登录后应能看到同一主题（数据在服务端 JSON）。
2. 使用酒馆管理员账号或句柄在 `admin` / `eu_admin` 等管理列表中的用户，确认帖子详情出现「删主题」「删楼层」，且删除后列表刷新正确。
3. 未登录酒馆会话时：应可浏览主题列表，发帖与回复应被服务端拒绝并提示。
