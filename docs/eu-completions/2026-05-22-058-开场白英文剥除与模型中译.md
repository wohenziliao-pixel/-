# 开场白：英文剥除 + 偏英文时模型译中

## 任务

世界书/角色卡开场白（first_mes）常含大段英文系统说明或纯英文叙事；用户希望进对话后以**简体中文**展示。

## 实现

1. **`euStripEnglishFromOpening`**：剥 meta 块、纯英文段、英文 instruction 行（同步，展示层也用）。
2. **`euOpeningNeedsZhLocalization`**：拉丁字母明显多于汉字时判定需翻译。
3. **`euTranslateOpeningToZhViaModel`**：轻量 generate（现代风 API），仅 system+user，不注入世界书。
4. **`euEnsureStorybookOpeningZh`**：先剥再译，按 uid+内容哈希缓存。
5. 挂钩：`euResolveStorybookOpeningForChat`、`openWorldChat` 解析开场白后；`euSanitizeMessageContentForDisplay` 剥英文。

## 说明

- 卡面原文仍为英文的**不会改磁盘 JSON**，仅会话展示用中文。
- 首次进书若需翻译，可能多等数秒（一次模型调用）。
- 主对话回复里的英文仍走既有 `sanitizeRpReplyForDisplay` 等逻辑。

## 路径

## 自测

1. 选英文为主的公共故事书进对话 → 开场气泡应为中文或中文为主。
2. 已是中文的开场 → 不应重复调用翻译。
3. 控制台可见 `[EU] opening zh translate` 仅在需要时。
