# EU 个人资料头像与侧栏顶栏灌水吧联动

## 问题

上传个人资料头像后，左下角侧栏与顶栏用户区未更新；灌水吧仍仅用渐变 emoji，未与本地保存的头像关联。

## 改动（`public/eu-demo.html`）

- 侧栏 `.user-avatar` 内 `<img>` 使用绝对定位铺满圆形容器，避免 flex 下尺寸为 0 导致头像不显示。
- 顶栏下拉按钮增加 `topbar-user-avatar-img` / fallback，`applyAvatarToUi` 同步更新。
- `getEuAccountAvatarForDisplay`：合并 `localStorage` 与写入失败时的 `window.__euAvatarDataUrlOverride`；`syncSidebarAvatarFromProfile` / `refreshAccountProfileForm` 使用之。
- `persistEuAccountProfile` 成功写入后清除 override；保存资料时若存在 override 则合并进 `p.avatarDataUrl` 再持久化。
- 灌水吧列表/楼主/楼层：`euTiebaAvatarSquareHtml`，当 `authorHandle` 与当前 `state.currentUser`（忽略大小写）一致时使用上述头像，否则保持渐变占位。
- 头像上传：`persist` 失败时仍 `applyAvatarToUi` + `setEuAvatarOverrideDataUrl`，并静默刷新吧列表；成功时 `persist` 内清除 override。

构建戳：`20260512-058`（以文件内为准）。

## 说明

他人帖子仍无法显示其自定义头像（头像仅存本机 `localStorage`，未上服务端）；仅当前登录用户在本地有资料时与吧内展示一致。
