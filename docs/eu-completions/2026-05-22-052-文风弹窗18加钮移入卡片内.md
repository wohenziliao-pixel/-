# 文风弹窗：18+/全年龄钮移入卡片内、compact 尺寸

## 任务

修正文风转换弹窗布局：红绿切换钮须在每条文风**对话框边框内**、文字右侧垂直居中；尺寸与手机顶栏 `all-ages-toggle--compact` 一致，不得被拉成整行宽条。

## 原因

切换钮原先与 `.writing-style-option` 并列于 flex 行外；全局 `button { width: 100% }` 使其撑满一行，呈现为独立红色横条。

## 实现

- 每条改为单一 `.writing-style-option-row` 卡片（边框/背景），内层 `writing-style-option-body` + 右侧 compact 钮。
- 点击卡片选文风；点钮 `stopPropagation` 仅切 18+/全年龄。
- 文案与手机顶栏一致：绿「全年龄」/ 红「含18+」。

## 改动路径

- `public/eu.html`（构建戳 `20260522-writing-style-toggle-inrow-v133`）

## 自测

硬刷新 v133 → 文风转换 → 每行右侧小圆角钮在框内、与手机顶栏同大；不再出现框外整行红条。
