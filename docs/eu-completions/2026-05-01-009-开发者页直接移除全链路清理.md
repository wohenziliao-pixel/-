# 任务目标

- 开发者模式页面中的资源操作从“移出我的世界”改为“直接移除”。
- 直接移除应执行：商城下架、相关文件删除、并尽可能清除系统中存在过的痕迹。

# 实施内容

1. 开发者页面按钮语义调整：
   - `renderDevItems()` 中按钮统一改为 `直接移除`。
   - 不再区分管理/普通文案，开发者页入口即执行强删除流程。

2. 强删除入口限制：
   - `deleteDevItem(id)` 增加页面校验，仅允许在 `page-dev` 执行，避免普通页面误调用。
   - 增加高风险确认文案，明确“下架 + 文件删除 + 痕迹清理”。

3. 新增强删除链路：
   - 新增 `hardDeleteResourceFromSystem(item, uid, title, typeName)`：
     - 故事书先执行 `removeConversationRuntimeByStorybook`；
     - 调用 `runBackendAuxiliary('deleteConversationFiles', ...)` 删除文件；
     - 清理规则缓存、当前激活故事书状态、正则状态、挂起详情状态；
     - 从 `devItems` 删除并持久化（实现商城下架）；
     - 刷新页面关联视图与状态栏。

4. 新增跨缓存痕迹清理：
   - 新增 `purgeResourceTracesAcrossLocalStorage(item, uid, title)`，遍历本地缓存：
     - 清理所有用户缓存中的 `eu_demo_acquired_items_*` 对应 UID；
     - 清理故事书规则缓存 `eu_demo_story_rules_*`；
     - 清理故事书会话缓存 `eu_demo_conversations_*`，并同步清理 `eu_demo_character_sessions_*` 的悬挂引用。

5. 兼容旧调用：
   - `deletePublicMallResource(id)` 改为转发到 `deleteDevItem(id)`，避免保留分叉删除逻辑。
