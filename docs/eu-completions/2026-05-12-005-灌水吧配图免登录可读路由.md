# 灌水吧配图免登录可读路由

## 任务

用户反馈灌水吧**正文里看不到图**（与列表缩略图同源）：配图 Markdown 使用 `/user/images/...` 时，该静态路由在 `requireLoginMiddleware` 之后，未带酒馆会话的请求会 **403**，浏览器表现为裂图。

## 做了什么

- 灌水吧上传改为写入 **`DATA_ROOT/eu-tieba-media/`**（全局目录，不按用户分夹）。
- 上传接口返回 **`/api/eu/tieba/media/<filename>`**，与 `server-main` 中挂在登录前的 `app.use('/api/eu/tieba', …)` 一致，**匿名 GET 可读**。
- 新增 **`GET /api/eu/tieba/media/:filename`**：白名单文件名 `eu_tieba_<digits>_<alnum>.jpg`，路径穿越校验后 `sendFile`。
- **`extractFirstImageUrl`** 与裸链匹配支持上述 API 路径，列表 `thumbUrl` 仍可用。
- **`eu-demo.html`** 中 `euTiebaRichContentToHtml` 将 `![](/api/eu/tieba/media/...)` 识别为可渲染 `<img>`。

## 改动路径

- `src/endpoints/eu-tieba.js`
- `public/eu-demo.html`

## 自测建议

1. **重启 Node**（SillyTavern）后发帖配图，正文与列表应出现图；DevTools 中图片请求 URL 为 `/api/eu/tieba/media/...` 且状态 **200**（未登录主站也可打开 EU 页试列表/详情）。
2. **旧帖**若正文仍是 `/user/images/.../eu-tieba/`，在未登录时仍可能 403；可删帖重发或手动把 Markdown 改为新 API 路径（若仍保留旧文件在用户目录）。
