# 2026-05-01-013 我的世界侧栏同步故事书会话

## 任务
- 修复：从故事书页点开的书不会出现在侧栏「我的世界」子菜单中。

## 原因
- `getCharacters()` 仅列出 `conversationStore` 中 `messages.length > 0` 的会话。
- 进入世界聊天时若先执行 `decontaminateConversationMessages`，开场白等内容可能被净化为空并从 `messages` 中移除，导致会话变成 0 条消息，侧栏永远不显示；同时 `startStorybookChat` 路径也未保证子菜单即时刷新。

## 改动
- `public/eu-demo.html`
  - `getCharacters`：改为列出所有已在 `characterSessions` 中绑定且 `conversationStore` 存在的会话（允许 0 条消息）。
  - `openWorldChat`：结束时调用 `updateWorldSubmenu()`，保证进入聊天后侧栏与当前会话一致。

## 用户自测
1. 在故事书页点开任意已获取的故事书，展开侧栏「我的世界」，应立刻出现对应「故事书·…」条目。
2. 对开场白易被净化的书重复一次：即使消息列表被净化为空，侧栏仍应保留该会话入口。
