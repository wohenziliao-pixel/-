# 关闭 8000 旧进程并固定 8017 一键启动

## 任务

用户要求：
- 关掉旧端口（8000）进程，避免串线；
- 桌面提供连接新进程（8017）的一键启动。

## 处理

- 已关闭旧的 8000 监听进程（当前 8000 无 LISTENING）。
- 更新桌面脚本 `C:\Users\Administrator\Desktop\Start-EU-Chat.bat`：
  - 启动前自动清理 8000 监听进程；
  - 启动本仓库 SillyTavern；
  - 自动打开 `http://127.0.0.1:8017/eu-demo.html`。
- 同步更新仓库脚本 `Start-EU-Chat.bat`，保持一致逻辑，便于后续覆盖桌面版本。

## 说明

若任务栏固定的是旧快捷方式，请重新固定桌面这份 `Start-EU-Chat.bat`。
