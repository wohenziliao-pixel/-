# 设定集：全局与书域拆分注入

## 任务目标

对齐 EU 与酒馆挂载语义：「设定集」里用户手动勾选的全局生效，与随当前故事书书域联动的设定集分开注入与文案，避免混在同一段「全局世界书」说明中；不靠文件内容猜测类型，仍以 `dev-type` / 资源类型与 UI 选择为准。

## 做了什么

- `getManualGlobalSettingUids()`：仅 `state.activeGlobalSettingUids` 中已获取的设定集，并清洗无效 uid。
- `getStorybookScopedSettingUidsForPrompt()`：当前有效故事书 + 书域联动列表，排除已在全局中的 uid，避免双注。
- `appendSettingItemsExcerptLines`：全局块与书域块共用条目摘录格式。
- `buildGlobalSettingsSystemMessage()`：只使用手动全局；补充 `identifier: euGlobalSettingsWorldbook`。
- `buildStorybookScopedSettingsSystemMessage()`：新书域 system 块，`identifier: euStorybookScopedSettings`。
- `buildBudgetedMessages`：原生栈、strict 副本、降级栈均在合适顺序插入书域块（在「新增规则」前、全局块前）。
- `toggleGlobalSetting`：仅切换手动全局集合，toast 与合并集语义一致。
- 设定集商城列表：区分「已启用（全局）」与「随本书」提示；计数区分全局与随书（随书为去重后可注入数）。
- `updateWorldChatFeatureStatus` / `getEuFeatureProbe` / `dumpEuStorybookPromptAudit`：探针字段区分手动全局与随书注入。
- 在 `normalizeDevType`、`buildStorybookWorldInfoText` 等处增加简短 EU↔酒馆语义注释。

## 改动路径

- `public/eu-demo.html`

## 用户自测建议

1. 仅书域联动、未点「启用为全局」：对话中应出现书域 system 块，不应再出现「全局勾选」式标题的同内容重复。
2. 同一设定集同时全局 + 随书：提示中随书计数为 0（不双注），全局块仍含该设定集。
3. 设定集库卡片：仅随书时显示「随本书」标签与说明；点「启用为全局」后变绿且书域块中不再重复该 uid。
