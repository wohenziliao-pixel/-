# 灌水吧选图失败修复与插入预览

## 问题

部分环境下「插入图片」选取失败；插入后无缩略图预览。

## 处理

- 去掉嵌套在 `<label>` 内的文件控件与 `input[style=display:none]+button.click()` 组合，改为 **`<label for="fileId">` + 屏幕阅读器式隐藏 `input[type=file]`**，避免 WebView/部分浏览器拦截程序化点选。
- 发帖弹窗：正文下增加 **「正文中的图片预览」** 条带；回复区同理；`oninput` 与插入后调用 `euTiebaSyncImagePreview`。
- 上传前校验酒馆已登录；上传失败区分 403/413 与 JSON `error`；客户端长边预压改为 **1920**。
- 详情渲染中相对路径 `user/images/...` 补全前导 `/`。

## 路径

- `public/eu-demo.html`（`EU_CLIENT_BUILD_STAMP`：`20260512-057`）

## 自测

灌水吧 → 发帖 → 点「选择图片」应弹出系统文件框；选图后正文出现 `![](/user/images/...)` 且预览条出现缩略图；未登录时应提示先登录酒馆。
