# EU 个人资料页（社交信息 + 自定义头像）

## 功能

- 左下角头像圆圈改为可点击按钮，进入 **`page-account`** 个人资料页。
- 顶栏用户下拉增加 **「个人资料」** 入口。
- 区块：头像（上传 / 移除）、显示名称、简介、基本资料（网站、地区）、社交（QQ、微信、B 站、GitHub、X、Discord、对外邮箱）。
- 数据存 **`localStorage`** 键 `eu_demo_account_profile_<handle>`，与现有会话/商城分用户策略一致。
- 头像：选图后 canvas 压缩为 JPEG（约 320 边、`data:` URL），避免撑爆 localStorage。
- 登录后 `enterApp` 会应用已保存的 **显示名称** 与 **侧边栏头像**；`showPage('account')` 会刷新表单。
- 修复：`showPage` 在未知页名时 `label` 为空导致所有侧栏项 `includes('')` 全亮的问题；`account` 与顶栏无对应 tab 时清除顶栏高亮。

## 路径

- `public/eu-demo.html`（`EU_CLIENT_BUILD_STAMP` → `20260510-052`）

## 说明

- 资料为 **浏览器本地**，非服务端酒馆用户 JSON 的一部分；换浏览器需重新填写。
- 若需与酒馆头像 API 同步，可后续再接 `/api/avatars` 等。
