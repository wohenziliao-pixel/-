# 手机版故事书对话排版修复

## 任务

手机进故事书对话：标题被压成竖排（如「晴天」/「局！」分行）、开场白底部被挡、排版难读。

## 原因

- `#page-world-chat` z-index 低于 `.topbar-mobile`，且 `top:0` 与顶栏重叠。
- 会话头一行塞标题 + 两条状态 badge，`min-width:0` 把标题挤到极窄。
- 全局 `word-break: break-word` 在极窄容器下中文逐字断行。

## 实现

- 对话中隐藏手机顶栏；`#page-world-chat` 提 z-index。
- 标题区改纵排：标题独占一行，隐藏冗长 feature badge。
- 消息区与气泡：`word-break: normal`、`line-break: auto`、全宽滚动。
- `syncWorldChatLayout` 用 `innerHeight` 计算可视高度。

## 路径

- `public/eu.html`（`20260522-mobile-world-chat-layout-v138`）

## 自测

手机或窄屏进故事书：标题横排可读；开场白可滚到底；底栏不挡最后一行。
