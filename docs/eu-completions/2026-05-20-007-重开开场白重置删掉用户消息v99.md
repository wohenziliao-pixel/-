# 重开后聊天历史被开场白重置删掉（v99）

## 现象

- 已是 v98，`serverBytes` 与本机一致，能自动进上次故事书对话。
- 界面只见大段开场白/状态块，**看不到用户发过的话**（如「发生了什么」）。
- `euDebug` 可能仍有 `localMessages`，但重开一次后变少或只剩 AI 开场。

## 根因

`openWorldChat` 在 `shouldResetOpening` 为 true 时，将 `conv.messages` **整表替换**为仅一条 assistant 开场白，**用户消息被丢弃**并 `persistConversationRuntime` 写回云端。

重开时从故事书重新拉开场白，旧 assistant 条被标为 unusable，触发该分支。

## 修复（v99）

- `euRebuildMessagesKeepingUserTurns`：重置开场白时**保留全部 user 轮次**。
- `euCharacterNamesMatch`：`故事书-` / `故事书·` 互认。
- `tryRestoreLastWorldChatSession`：用 `euFindConversationKeyByCharacterName`，`openWorldChat(..., { forceConvKey })`。
- 构建戳：`20260520-conversation-keep-user-msgs-v99`。

## 路径

- `public/eu.html`

## 部署

`git pull` + 重启 Node；浏览器 Ctrl+F5 见 v99。

## 验收

1. 发「测」→ 关浏览器 → 再开：应同时看到**开场 + 「测」/「发生了什么」**气泡。  
2. `await euDebugConversationCloud()` → `localMessages` ≥ 1 且重开后不减少。
