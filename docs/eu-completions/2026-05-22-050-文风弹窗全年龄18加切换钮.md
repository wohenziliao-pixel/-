# 文风弹窗：每档全年龄 / 18+ 切换钮

## 任务

在文风转换弹窗每一行右侧增加与顶栏一致的红绿切换钮：全年龄（绿）仅注入基础文风 System；18+（红）注入完整「深渊欲火」成人 System。

## 实现

| 项 | 说明 |
|----|------|
| UI | `.writing-style-option-row` + `.writing-style-adult-toggle`（复用 `.all-ages-toggle` 样式） |
| 持久化 | 故事书 meta `writingStyleAdult: { modern, literary, … }`，按书保存 |
| 18+ | `EU_WRITING_STYLE_AGENT_SYSTEM`（原有完整版） |
| 全年龄 | 新增 `EU_WRITING_STYLE_AGENT_SYSTEM_SFW`（无露骨词库/性癖指令） |
| 篇幅 nudge | 18+ 用原硬指标；全年龄用 `EU_WRITING_STYLE_LENGTH_NUDGE_SFW` |

默认：未配置时视为 **18+**（`true`），与旧行为一致。

## 改动路径

- `public/eu.html`（构建戳 `20260522-writing-style-adult-toggle-v131`）

## 自测

1. 硬刷新 v131，打开文风转换。
2. 每行右侧：绿「全年龄」/ 红「18+」可点，不触发选文风（`stopPropagation`）。
3. 全年龄下发一句：控制台可见注入为 SFW System（开发者可看 probe）；正文应无露骨词库导向。
4. 切回 18+ 再发：恢复完整 System。
5. 换故事书后各文风开关独立记忆。
