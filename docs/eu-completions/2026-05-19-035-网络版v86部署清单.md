## 本机已执行

- `git add` 上述三文件 + 研发日志/完成单
- `git push origin main`（见提交哈希）

## 服务器操作（需 SSH）

```bash
cd /opt/SillyTavern   # 以实际路径为准
git pull origin main
pm2 restart all       # 或 systemctl / 手动 node 重启
grep "EU_CLIENT_BUILD_STAMP" public/eu.html | head -1
```

**不必**为本批单独传 `data/eu-public/mall`（除非同时要补 642 本书库）。

可选书库同步（与 v82 相同）：WinSCP 合并 `mall/resources` + `mall/thumbs` → `node tools/eu-mall-rebuild-index.mjs` → 再重启。

## 验收

1. 无痕打开 `eu.html`，F12 控制台：`client build` 含 `v86`。
2. 故事书页删一本 → 强刷仍不在列表。
3. 开发者模式编辑已上架公共书 → 有标签与成人开关。
4. 两浏览器同账号：对话可续（需发过消息并等 push）。

## 勿做

- 勿覆盖线上 `data/_storage/`、用户 `data/<handle>/`。
- 勿提交 `tools/eu-mall-batch.config.json`。
