# 对话云同步跨浏览器续聊

## 任务
同一账号需在不同浏览器/设备读取聊天历史，不能仅依赖本机 localStorage。

## 做了什么
- `eu-browser-state` 白名单增加：`eu_demo_conversations_<handle>`、`eu_demo_character_sessions_<handle>`、`eu_demo_last_chat_resume_<handle>`（单键最大约 4MB）。
- 发消息/保存会话后 debounce 推送到 `/api/eu/browser-state`（与商城云同步同通道）。
- 登录时先 `GET` 云快照再 `loadConversationRuntime()`，按 `cloudAt` 合并较新一方。
- 超长会话推送前截断（每会话保留最近约 96 条、单条约 12k 字）。

## 改动路径
- `src/endpoints/eu-browser-state.js`
- `public/eu.html`

## 部署
`git pull` 后无需单独命令；用户强刷 `eu.html?v=51`。

## 自测
1. 账号 A 在 Chrome 聊若干条，等约 3 秒或关页。
2. 同一账号在 Safari/另一电脑登录，应看到相同历史并自动进上次对话。
3. 极长会话可能被截断（见上）；单账号云快照过大时关注 `data/<handle>/eu-mall-browser-state.json` 体积。
