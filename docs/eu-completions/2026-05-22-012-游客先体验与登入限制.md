# 游客先体验主站与登入限制

## 任务

调整产品流程：**先体验网页，满意后再注册/登录**；未登录为游客，右上角显示「登入」进入原登录页。游客灌水区不可发帖/回复；故事书对话每会话最多 **10** 句 user 消息，**不保存**聊天记录（离开页面即清空）。

## 做了什么

- 打开 `eu.html` 默认 **`enterGuestApp`** 进商城主界面（无酒馆 session 时不再先挡登录页）。
- 已登录用户仍走 `tryRestoreEuAppSession` → `enterApp`。
- 右上角/侧栏：游客显示 **「登入」**，点击 → `openEuLoginFromGuest()` → 原 `page-login`。
- 登录成功 `enterApp` 关闭 `euGuestMode`；退出登录后回到游客主站（非登录墙）。
- 游客：`persistConversationRuntime` / `loadConversationRuntime` 不写 localStorage、不推对话云；`beforeunload`/`pagehide` 清空内存会话。
- 故事书发送：`EU_GUEST_MAX_USER_MESSAGES = 10`（不含开场 kickoff）。
- 灌水区：`euTiebaOpenNewThreadModal` / `euTiebaSubmitReply` 拦截游客。
- 构建戳：`20260522-guest-first-experience-v110`。

## 改动路径

- `public/eu.html`

## 自测

1. Ctrl+Shift+R，未登录打开 `http://127.0.0.1:8000/eu.html` → 直接进商城/主界面，非登录页。
2. 右上角为 **「登入」**，点击后出现登录/注册页。
3. 游客进故事书对话发 11 句 → 第 11 句 Toast 限制；刷新或关标签后对话消失。
4. 游客灌水区点发帖/回复 → Toast 提示登入。
5. 登录后右上角为账号下拉，对话可正常保存与云同步。
