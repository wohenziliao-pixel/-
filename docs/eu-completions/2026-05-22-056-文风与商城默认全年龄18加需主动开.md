# 文风与商城：默认全年龄，含18+ 须主动开启

## 任务

用户默认应为**全年龄**；含18+ 须主动打开。统一文风弹窗每档切换与右上角全年龄设置的逻辑与文案。

## 实现

| 项 | 原逻辑 | 现逻辑 |
|----|--------|--------|
| 文风 `writingStyleAdult` | 未设视为 18+（`!== false`） | 未设视为**全年龄**；仅 `=== true` 为含18+ |
| 右上角 `allAgesMode` | 已默认 `true`（商城 SFW 过滤） | 保持；文案与文风说明对齐 |
| 弹窗说明 | 旧句 | 标明默认全年龄、右上与叙述可分别设 |
| 选文风 Toast | 可带 API（开发者） | 仅「全年龄叙述（默认）/ 含18+ 叙述」 |

## 改动路径

- `public/eu.html`（`20260522-writing-style-default-sfw-v135`）

## 自测

1. 新故事书 / 清空 `writingStyleAdult` 后发消息 → SFW System。
2. 点某档「含18+」→ 红钮 → 再发 → 完整 System。
3. 右上默认绿「全年龄」；切红「含18+」仅影响商城列表，不自动开文风含18+。
