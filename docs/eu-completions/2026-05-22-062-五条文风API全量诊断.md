# 五条文风 API 全量诊断

## 任务

用户对话失败（generate 404 + messages 未定义）；要求把五条文风 API 全部检查一遍说明原因。

## 结论摘要

| 文风 | 连接名 | 来源 | 模型 | 密钥槽 |
|------|--------|------|------|--------|
| 现代风 | DEEPSEEKV3 | openrouter | deepseek-chat-v3 | api_key_openrouter + profile secret-id |
| 文学风 | Euryale 70B | openrouter | euryale-70b | 同上 |
| 温柔风 | GLM5.1 | custom | glm-5.1 | api_key_custom + secret-id（勿 exclude） |
| 创意风 | GROK4.3 | xai | grok-4.3 | api_key_xai + secret-id |
| 重口风 | VENICE | custom | venice-uncensored | api_key_custom + secret-id |

**当前线上「全部不能对话」**：`POST /api/backends/chat-completions/generate` 返回 **404** 时，五条文风共用该接口，与单条 API 配置无关；须先修服务器反代/进程。

**messages is not defined**：v139 已修（非流式兜底笔误）。

## 实现

- `auditEuWritingStyleApis()` / `dumpEuWritingStyleApiAudit()` 增强（`public/eu.html`，v140）。
- 服务器 CLI：`node tools/eu-audit-writing-style-apis.mjs [handle]` 读 `data/<handle>/settings.json` 核对五连接。

## 自测

```js
await auditEuWritingStyleApis()
// 修通 generate 后实测上游：
await auditEuWritingStyleApis({ probeGenerate: true })
```
