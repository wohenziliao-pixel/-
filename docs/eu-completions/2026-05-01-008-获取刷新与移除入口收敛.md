# 任务目标

- 修复“获取成功但我的世界不同步刷新”的体验问题。
- 将“移除故事书”严格限制在开发者模式特定页面执行，避免普通用户页面误操作。
- 清理多次移除后可能残留的会话态/正则态引用。

# 实施内容

1. 获取后即时同步：
   - 在 `acquireMallItem()` 中，`refreshLinkedViews()` 后追加 `updateWorldSubmenu()`，
   - 确保“我的世界”侧栏列表在获取成功后立即刷新，无需手动刷新页面。

2. 移除入口权限收敛：
   - `removeMallItemFromMyWorld()` 新增页面上下文校验：
     - 默认仅允许在 `page-dev`（开发者页面）执行；
     - 非开发者页面调用会提示并拒绝。
   - `deleteDevItem()` 显式以 `{ allowOutsideDevPage: true }` 调用，保证开发者页操作可用。
   - 删除故事书页卡片上的“移出我的世界”按钮，普通用户界面不再暴露移除入口。

3. 多次移除残留清理增强：
   - 故事书移除后若命中当前激活书，额外清理：
     - `state.activeRegexRules = []`
     - `state.regexLoaded = false`
   - 若详情弹窗挂在被移除资源上，清理 `state.pendingMallItemUid`。
