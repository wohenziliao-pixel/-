# 故事书库空但「我的世界」仍显示会话

## 任务

用户删书后故事书页显示 0 本，侧栏仍出现「吹哨人」「南文忆」，以为没删掉。

## 说明

- **故事书页** = 已获取的故事书库（当前 0 = 库已空）。
- **我的世界侧栏** = 历史聊天会话，删库不会自动清会话。

## 改动

- `removeConversationRuntimeByStorybook`：按书名匹配 `故事书·标题` / 显示名，删书库时连带清会话。
- `euClearMyWorldHistorySessions()`：故事书为空且侧栏有会话时，页内按钮「清理全部历史会话」。
- 删单条会话 / 批量清理后 `euPushConversationCloudNow`，避免云端拉回。
- 构建戳：`20260519-myworld-orphan-sessions-v89`

## 自测

1. 故事书 0 本、侧栏有 2 条 → 点「清理全部历史会话」→ 侧栏清空。
2. 强刷后会话不应再出现（需 POST conversations 成功）。

`public/eu.html` pull + 重启 node + 强刷 v89。
