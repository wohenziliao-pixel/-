# 任务目标

- 将故事书正则加载确认从浏览器原生 `confirm` 改为站内 UI 弹窗。
- 解决原生弹窗显示地址/IP（如 `127.0.0.1:8000`）的问题，避免敏感信息暴露。

# 实施内容

1. 在 `public/eu-demo.html` 新增弹窗：
   - `#regex-load-confirm-modal`，使用现有 `modal-overlay/modal` 样式体系，居中显示；
   - 文案区域 `#regex-load-confirm-text` 动态填充书名与正则条数；
   - 按钮改为“否，跳过 / 是，加载”。

2. 新增确认逻辑函数：
   - `askRegexLoadConfirm(bookTitle, regexRuleCount)`：打开弹窗并返回 Promise；
   - `resolveRegexLoadConfirm(accept)`：关闭弹窗并回传用户选择。

3. 替换调用点：
   - `startStorybookChat()` 改为 `async`；
   - 将 `confirm(...)` 替换为 `await askRegexLoadConfirm(...)`；
   - 保持原有后续行为（toast 提示、regexLoaded 状态写入）不变。
