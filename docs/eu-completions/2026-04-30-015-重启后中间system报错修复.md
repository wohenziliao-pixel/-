# 2026-04-30-015 重启后中间 system 报错修复

## 任务
- 排查“酒馆每次重启后不能正常对话”的原因并修复。

## 根因
- 连接本身正常（`/csrf-token` 与 llama `/v1/models` 均返回 200）。
- 失败来自模型后端校验：`Input contains system message in the middle`。
- 部分请求在 prompt 管道后仍可能出现 system 消息不在首位（尤其 OpenAI/CUSTOM 兼容链路），导致反向代理拒绝。

## 改动
- `data/default-user/settings.json`
  - `oai_settings.squash_system_messages` 改为 `true`。
- `src/endpoints/backends/chat-completions.js`
  - 新增 `normalizeSystemMessagesAtFront(messages)`。
  - 在 `/generate` 路由中，对 `OPENAI` 与 `CUSTOM` 源的消息统一做“system 合并置顶”规范化，再下发到后端。

## 影响路径
- `data/default-user/settings.json`
- `src/endpoints/backends/chat-completions.js`

## 用户自测
- 重启 SillyTavern 后直接发消息，不应再出现 “system message in the middle” 的 400。
- 若切换不同模型/代理，仍应保持可对话（系统提示始终在首位）。
