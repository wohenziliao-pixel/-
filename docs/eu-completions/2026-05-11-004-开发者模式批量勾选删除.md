# 开发者模式批量勾选删除

## 任务目标

在开发者模式资源列表中增加批量勾选删除能力，减少逐条点击「移除」的操作成本。

## 做了什么

- 在开发者页右侧列表标题下新增批量操作区：
  - `全选/清空可见`
  - `批量删除已勾选`
  - `已勾选 N 项` 状态提示
- 列表卡片新增勾选框（`勾选删除`），支持逐项选择。
- 新增选择状态与批量逻辑：
  - `selectedDevItemIds`（勾选集合）
  - `toggleDevItemSelection`
  - `getFilteredDevItemsForCurrentView`
  - `toggleSelectAllVisibleDevItems`
  - `bulkDeleteSelectedDevItems`
- 批量删除复用原有硬删除链路，确保清理一致：
  - 仍会走会话清理、localStorage 痕迹清理、商城/侧栏刷新。
- `hardDeleteResourceFromSystem` 增加可选参数：
  - `silent`：静默单条 toast（批量模式避免刷屏）
  - `deferRender`：延迟逐条重渲染（批量模式统一末尾刷新）

## 改动路径

- `public/eu-demo.html`

## 用户自测建议

1. 进入开发者页，筛选某类型后点 `全选/清空可见`，勾选数应同步变化。
2. 勾选多条资源后点 `批量删除已勾选`，确认后应一次完成并提示成功/失败数。
3. 删除后检查对应资源是否同时从列表、商城可见项和「我的世界」关联会话中清理。
