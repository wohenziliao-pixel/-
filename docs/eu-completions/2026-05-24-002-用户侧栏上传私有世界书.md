# 用户侧栏「上传世界书」（私有库，不进商城）

## 任务

在左侧栏「灌水交流区」下方增加 **上传世界书**（图标 📕），供普通用户使用；与开发者模式批量上架不同：不上传公共商城，仅本账号可见，写入故事书库并在服务器独立目录备份。

## 实现

### 服务端

- 新模块 `src/endpoints/eu-private-storybooks.js`
- 挂载：`/api/eu/private-storybooks`（需登录，`server-main.js`）
- 数据目录：`data/eu-private-storybooks/<handle>/`
  - `resources/<id>.json` 正文
  - `thumbs/<id>.jpg` 封面
  - `index.json` 元数据索引
- API：`GET /` 列表、`GET /:id` 全文、`POST /` 上传、`DELETE /:id` 删除、`GET /:id/thumb` 封面
- UID 前缀：`eu-private-<id>`，与 `public-*` 商城隔离

### 前端

- `public/eu.html` 构建戳 `20260524-private-worldbook-upload-v144`
- 侧栏按钮 + 隐藏 file input（`.json` / `.png`）
- 上传后：POST 私有 API → 写入本机 acquired/devItems → 跳转故事书页
- 登录/延后初始化：`euSyncPrivateStorybooksFromServer()` 合并服务端列表
- 进对话：`euFetchAndMergePrivateStorybook` 水合全文
- 故事书卡片角标「私有上传」；删除时同步删服务器备份

## 改动路径

- `src/endpoints/eu-private-storybooks.js`（新）
- `src/server-main.js`
- `public/eu.html`

## 部署

1. `git pull`（含 `eu-private-storybooks.js`）
2. **`systemctl restart sillytavern`**（新路由必须重启）
3. 浏览器 Ctrl+F5，构建戳 **v144**

清理某用户全部私有备份：删除 `data/eu-private-storybooks/<handle>/` 目录即可（不影响商城 `eu-public`）。

## 自测

- [ ] 登录用户见侧栏「📕 上传世界书」，游客不可见
- [ ] 上传 JSON/PNG 后出现在「故事书」列表，带「私有上传」标签
- [ ] 商城搜索不到该书；其他账号 API 无法读取
- [ ] 可进对话；删除后本机与服务端目录均移除
