# 回复重复、流式后重写与温柔/创意风 500 修复

## 任务

用户反馈三项问题：

1. 文本有时会无限重复  
2. AI 回复有时流式显示完成后又整段「重写」  
3. **温柔风**、**创意风** 不能回复，返回 HTTP 500  

## 原因简述

| 现象 | 主要原因 |
|------|----------|
| 无限重复 | 自动续写 + 尾部周期重复未裁剪；段落去重不足 |
| 流式后又重写 | 首轮流式正常仍触发退化重生成、自动续写、收尾时强制 `innerHTML` 覆盖气泡 |
| 温柔/创意 500 | 预设 `customUrl` 与模型组合错误（如 `z-ai/glm-5.1` 直连智谱）；或未读到 Connection Manager 配置即发请求 |

## 实现

### `public/eu.html`（`20260522-reply-dedup-style-route-v120`）

1. **重复**：`trimTrailingPeriodicLoop` / `collapseRepeatingTextLoops`；续写门槛提高（≥88% max_tokens、尾部循环则不再续写）。  
2. **流式后重写**：`euFirstPassStreamHealthy` 跳过退化重试；`finishReason === 'stop'` 且内容完整则跳过自动续写；`euDisplayRoughlySame` 避免气泡无意义整段替换。  
3. **温柔/创意风**：去掉预设里易误导的 `customUrl`；连接名模糊匹配；`validateEuWritingStyleGenerationRoute` 在发消息前报错；切换文风时刷新 `connectionManager` 缓存。
