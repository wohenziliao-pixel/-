# 任务目标

- 强制“公用资源删除”只允许管理侧执行，用户侧只能清理自己的数据。

# 实施内容

1. 在 `public/eu-demo.html` 新增管理权限判断：
   - `EU_MANAGEMENT_USERS`：管理账号白名单（`admin / administrator / root / eu_admin`）。
   - `isManagementUser()`：统一权限校验函数。

2. 新增管理侧删除公用资源函数：
   - `deletePublicMallResource(id)`：
     - 非管理侧直接拒绝并提示无权限；
     - 管理侧二次确认后才会真正删除 `devItems` 公用资源并持久化。

3. 开发者列表按钮按权限分流：
   - 管理侧显示 `删除公用资源`（调用 `deletePublicMallResource`）。
   - 非管理侧显示 `移出我的世界`（调用 `deleteDevItem` -> `removeMallItemFromMyWorld`，仅清用户数据）。

# 用户自测建议

- 普通账号：
  - 开发者列表应只看到“移出我的世界”；
  - 不应出现“删除公用资源”入口。
- 管理账号（白名单）：
  - 可见“删除公用资源”；
  - 删除后商城公用资源应同步消失。
