# Token 计数报错（xAI + 分词器 API 失败兜底）

## 任务

用户打开 `index.html` 能进界面，但发送时出现红条：**「Token 计数时发生错误。详见控制台。」** 输入框文字不消失、用户消息不进正文。

## 根因（不必再装对照版）

| 现象 | 原因 |
|------|------|
| 红条「Token 计数时发生错误」 | `openai.js` 在组装 Chat Completion 时 `preparePromptsForChatCompletion` / `populateChatCompletion` 抛错，落入 `catch` 的**通用分支**（非预算超限、非角色名非法） |
| 与今晚回退的关系 | 为恢复黑屏/按钮，曾 `git checkout` **整份** `public/scripts/tokenizers.js`，把 **5 月 21 日已写好的 xAI 分词器 + ajax 失败兜底** 一并撤掉 |
| xAI 特有问题 | `getTokenizerModel()` **无 XAI 分支**，默认走 `gpt-3.5-turbo` tiktoken；与当前 Grok 源不匹配，且 `/api/tokenizers/openai/count` 失败时 `countTokensOpenAIAsync` **无 try/catch**，异常冒泡 → 红条 + 发送流程中断 |
| 不必另装 1.12 对照 | 仓库内 `docs/eu-completions/2026-05-21-003` 已记录同一根因；对照版只会看到「未改 tokenizers 时 xAI 也会炸」 |

## 做了什么（最小改动，仅 tokenizers）

- `public/scripts/tokenizers.js`
  - `getTokenizerModel`：`chat_completion_sources.XAI` → 使用 `deepseek` 近似分词器
  - `countTokensOpenAIAsync`：ajax 失败时 `guesstimate` 估算并写缓存，**不再 Uncaught**，避免阻断 `Generate`

未恢复：发送同步写正文、遮罩强制关闭、openai 自动连接等大改（避免再次黑屏/按钮全死）。

## 用户自测

1. **Ctrl+Shift+R** 强刷 `http://127.0.0.1:8000/index.html`
2. 确认 API 源为 **xAI**，底栏已连接（有效）
3. 输入「可以了么」回车发送：红条不应再出现；输入框应清空；用户气泡应进正文
4. 若仍有红条：F12 Console 第一条红字全文发回（可能是 CSRF 过期 → 再强刷或重启服务后重开页）

## 若仍要装对照版

可选：另目录干净 `SillyTavern-1.17.0` 仅开 `index.html` + xAI，对比 `getTokenizerModel` 与 Console；**非必须**，本修复已对准文档 003 根因。
