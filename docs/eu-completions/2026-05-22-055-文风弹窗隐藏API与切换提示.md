# 文风弹窗：隐藏 API 行、切换任意档均 Toast

## 任务

网络版 v133 已上线后用户反馈：弹窗底部仍显示 `API openrouter/...`；切换 18+ 时未见 Toast 提示。

## 原因

- API 行：`euCanShowWritingStyleApiDetails()` 在**开发者模式**下为 true，弹窗会拼 `apiHint`。
- Toast：此前仅切换**当前正在用的文风**时才提示。

## 改动

- `renderWritingStyleModalList`：弹窗不再展示 API/模型路径（运维用 `dumpEuWritingStyleApiAudit()`）。
- `toggleWritingStyleAdultMode`：任意一档切换均 Toast「全年龄叙述 / 含18+ 叙述」。

## 路径

- `public/eu.html`（`20260522-writing-style-modal-no-api-v134`）

## 自测

硬刷新 v134；文风弹窗无 API 行；点右侧钮有 Toast；绿=全年龄、红=含18+。
