# EU 换端口/换网址后商城与「我的世界」变空

## 结论（给用户）

次元姬 EU 的商城自建条目、已获取列表、会话等，主要存在浏览器 **`localStorage`** 里，且按 **「协议 + 主机名 + 端口」** 整站隔离。

因此 `http://127.0.0.1:8000`、`http://127.0.0.1:8017`、`http://127.0.0.1:8317`、`http://localhost:…` 在浏览器眼里是**不同网站**，各自一份存储；换网页（换端口）后看到的是**新站点下的空库**，旧数据仍在**旧站点**下。

## 代码依据（便于维护）

- 商城自建资源：`eu_demo_dev_items`（及迁移用的分仓键名）
- 按用户：`eu_demo_acquired_items_${userKey}`、`eu_demo_conversations_${userKey}`、`eu_demo_character_sessions_${userKey}` 等（`userKey` 为登录名或 `guest`）

## 恢复方式

1. 用**当初导入时的同一地址**打开（同一 host + 同一端口），数据会回来。
2. 若需迁到新端口：Chrome → **F12** → **Application** → **Local Storage** → 选中旧 origin → 找到以 `eu_demo_` 开头的项 → 复制到新 origin（或导出为文件再手动合并，注意 JSON 格式）。

若曾在浏览器里对该站点执行「清除网站数据」，则对应 origin 下的数据会被真正删除，上述方式也无法恢复。
