# 本机 browser-state 瘦身（108MB eu_demo_dev_heavy）

## 现象

Console：`[EU] browser-state large, partial extract 122253344`，登录后拉云端快照极慢。

## 根因

`data/wohenziliao/eu-mall-browser-state.json` 约 **161MB**，其中 **`eu_demo_dev_heavy` ≈ 108MB**（开发者本机书库重数据误进云快照）。

## 处理

- 备份：`data/wohenziliao/eu-mall-browser-state.json.bak-before-trim-20260522`
- 删除 `eu_demo_dev_heavy` 后文件约 **0.02MB**
- 保留：对话云、已获取列表、profile、dev_items 分片键等

## 自测

1. **Ctrl+F5** `eu.html` 重新登录 `wohenziliao`
2. Console **不应再**出现 `browser-state large, partial extract`（或长度很小）
3. 商城/故事书仍可用（重数据在 IndexedDB / 服务端商城，不靠 heavy 键）

## 恢复

若需还原 heavy：用备份文件覆盖 `eu-mall-browser-state.json` 后重启 node。
