# EU 拉取酒馆预设时按 chat_completion_source 解析模型名（含 xAI）

## 问题

`fetchStLiveGenerationProfile` 仅用 `presetRaw.openai_model` 作为 `model`，在酒馆预设为 **xAI (Grok)** 时，实际模型 ID 在 `xai_model` 中，导致 EU 请求体里模型名错误。

## 改动

- `public/eu-demo.html`：新增 `resolveStPresetModel`，与酒馆 `getChatCompletionModel` 的常见源字段对齐；`fetchStLiveGenerationProfile` 使用当前预设的 `chat_completion_source` 解析模型。
- `EU_CLIENT_BUILD_STAMP` → `20260503-034`。

## 自测

酒馆连接选 xAI、预设里选好 Grok 型号后，打开 EU 世界聊天发一条，在 Network 里看 `/api/backends/chat-completions/generate` 的 `model` 应与酒馆界面所选一致。
