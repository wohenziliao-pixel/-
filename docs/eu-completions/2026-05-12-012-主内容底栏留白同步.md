# 主内容区底部留白：商城最后一行「已获取」不被底栏遮挡

## 问题

登录后主内容 `.main-content` 使用 `padding-bottom: 80px`，而底部固定输入条（工具按钮 + `textarea` `min-height:58px` + 内外边距）实际更高，滚到底时商城等页最后一行卡片上的状态（如「已获取」）被遮住。

## 改动

- **`public/eu-demo.html`**
  - `.main-content` 的 `padding-bottom` 改为 `calc(var(--eu-bottom-input-pad, 120px) + env(safe-area-inset-bottom, 0px))`。
  - 新增 **`syncEuBottomBarReserveToCss`**：根据 `#bottom-input-bar.visible` 的 `getBoundingClientRect().height` 写入 `--eu-bottom-input-pad`（至少为高度 + 16px）；底栏隐藏时用较小占位。
  - **`ensureWorldChatLayoutSync`** 的 `resizeHandler` 与首次绑定末尾调用该同步；对底栏 **`ResizeObserver`** 触发时一并更新。
  - **`updateBottomChatActionVisibility`** 结束时调用（世界聊天隐藏侧栏按钮时底栏高度会变）。
  - **`enterApp`** 显示底栏后 `sync` + `requestAnimationFrame` 再测一次；**`showEuLoginPageLayout`** 隐藏底栏后同步。
  - **`DOMContentLoaded`** 在 `tryRestoreEuAppSession` 后 `rAF` 再测一次布局。
  - **`EU_CLIENT_BUILD_STAMP`** → `20260512-main-content-bottom-pad-sync`。

## 自测

登录后打开商城，滚到最底，最后一行卡片的「已获取」/「可获取」应完全露出在底栏上方；拉高输入框后留白应随之增加。
