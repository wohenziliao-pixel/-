## 黑屏说明（排查结论）

- 页面 `#preloader` 在 JS **模块加载完成并执行 `firstLoadInit` 之前**会盖住全屏；若模块解析失败（例如曾出现的 `eventSource` 重复 import），会表现为**只有灰黑底、无「Initializing…」**。
- 本机 `8000` 端口在监听，`/csrf-token` 与 `/index.html` 均 HTTP 200。
- 当前 `RossAscends-mods.js` 仅从 `script.js` 导入 `eventSource` 一次，与文档 `2026-05-21-015` 修复后状态一致。

## 用户自测

1. **关闭**该标签页，重新打开 `http://127.0.0.1:8000/index.html`（或 **Ctrl+Shift+R** 强刷，避免旧 `script.js` 缓存）。
2. F12 → Console：不应有 `has already been declared`、`Unexpected token` 等红字。
3. 若仍黑屏：在应用目录重启服务（`node server.js` 或桌面 `Start-EU-Chat.bat`），再重复步骤 1。
4. 次元姬入口仍为 `http://127.0.0.1:8000/eu.html`（根路径会 308 到 EU）；原版酒馆请始终用 **`/index.html`**。
