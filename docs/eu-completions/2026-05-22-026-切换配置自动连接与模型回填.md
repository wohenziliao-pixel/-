# 切换配置：恢复自动连接与连通后模型回填

## 问题

用户反馈：改操作顺序后切换配置时**不会自动连接**，连接后也**不会自动填入**已保存的模型。

## 原因

1. 用 `online_status !== 'no_connection'` 判断过严，连接稍慢时直接 **skip 模型阶段**。
2. `reconnectOpenAi()` 为异步，未等待 `ONLINE_STATUS_CHANGED` 变为有效就执行模型写入。
3. 模型列表未就绪时硬设 slug 失败，且未走 `/model` 模糊匹配。

## 改动

- `reconnectOpenAiAndWaitForProfile()`：切换时仍**自动点连接**，并等待状态变为有效（最多 20s）。
- 连通后 `finishPendingProfileModelApply()`：用 `/model` + 快照/`profile.model` 写入正确模型；监听 `ONLINE_STATUS_CHANGED` 作备份。
- 从 `connectionSnapshot` 回退读取模型；防止重复填入。

## 自测

硬刷新 → 每条配置先「更新配置」保存模型 → 切换配置应：自动连接 → 模型变为该条保存项（如 Euryale）。
