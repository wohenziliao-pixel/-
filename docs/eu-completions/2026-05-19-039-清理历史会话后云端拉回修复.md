# 清理历史会话后云端拉回修复

## 任务

用户点「清理全部历史会话」后，刷新/重登侧栏又出现吹哨人、南文忆等条目。

## 根因

1. `euPushConversationCloudNow` 在本地 `conversationStore` 为空时**直接 return**，从未把 `{}` 写到服务器。
2. 登录时 `euPullConversationCloudBeforeLoad` 仍从云端合并旧的三键快照，覆盖本机清空结果。

## 改动

- 新增 `euWipeConversationCloudNow()`：POST 空 `{}` 与带 `clearedAt` 的 resume。
- `euClearMyWorldHistorySessions` 清理后必调 wipe；失败时提示云端未更新。
- `euMergeConversationCloudFromServerItems`：本机已空且用户刚清理时，拒绝再合并服务器旧数据。
- 删至最后一条会话时自动 wipe。
- 构建戳：`20260519-conversation-cloud-wipe-v90`

## 自测

1. 强刷 v90 → 清理全部历史会话。
2. F12：`POST /api/eu/browser-state/conversations` 200，控制台 `[EU] conversation cloud wiped on server`。
3. 强刷或无痕重登：侧栏应为空。
4. `await euDebugConversationCloud()` → `serverBytes` 约 2（`{}`）。

## 部署

`public/eu.html` pull + 重启 node。
