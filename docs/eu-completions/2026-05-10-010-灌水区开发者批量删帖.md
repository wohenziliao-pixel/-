# 灌水区开发者批量删帖

## 任务

在 EU 开发者模式下，于灌水吧主题列表支持勾选多个主题并批量删除；服务端在配置允许且请求带开发者标识头时，允许已登录用户执行删帖（非版主场景，便于本地清理）。

## 改动

- `src/endpoints/eu-tieba.js`：引入 `getConfigValue`；新增 `canDeleteTiebaContent`（版主链，或 `euTiebaDevBulkDelete` 为 true 且 `X-EU-Tieba-Dev: 1` 且已登录有 handle）；`DELETE /thread/:id` 与 `DELETE /reply` 改用该判定。
- `public/eu-demo.html`：`stApiRequest` 第五参数合并附加请求头；灌水列表卡片用 `data-thread-id` + `euTiebaFeedCardClick`；开发者模式且已登录时显示勾选框与工具条（全选 / 取消全选 / 删除所选主题）；`euTiebaCanDeleteContent` / `euTiebaDeleteExtraHeaders`；删帖相关 `stApiRequest` 在开发者非版主时附带 `X-EU-Tieba-Dev`；`updateDevModeUi` 在灌水页激活时静默刷新列表；客户端构建戳 `20260512-064`。

## 用户自测

1. 酒馆已登录，开启 EU 开发者模式，进入灌水吧：列表应出现勾选框与批量工具条；勾选若干主题后「删除所选主题」应成功（默认 `config.yaml` 未关 `euTiebaDevBulkDelete`）。
2. 关闭开发者模式或退出登录：勾选与批量条应消失；单卡「删帖」仅版主/管理账号仍可见。
3. 将 `euTiebaDevBulkDelete` 设为 `false` 后重启服务：带开发者头的删帖应返回 403。
