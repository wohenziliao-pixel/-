# 2026-04-30-007 删除会话按故事书联动清理

## 任务
- 用户删除某个故事书会话时，默认同步删除该故事书在 EU 页面本地保存的所有会话记录（而非只删当前一条）。

## 改动
- 更新 `public/eu-demo.html` 的 `removeConversationRuntime`：
  - 删除目标改为「同故事书」范围：通过 `metadata.storybookUid`（优先）+ 标题回退匹配，批量收集会话键并删除。
  - 清理 `characterSessions` 中所有指向被删会话的映射。
  - 若当前活跃会话被删，自动退出会话页回到角色页。
  - 返回值由布尔改为删除条数，供 UI 提示。
- 更新 `doDelete` 提示：
  - 单条删除时保持原提示；
  - 批量联动删除时提示「同故事书共 N 条本地记录」。

## 影响路径
- `public/eu-demo.html`

## 用户自测
- 新开某故事书并生成多条本地会话（含分支/残留），删除其中一条，确认同故事书会话一起从 EU 页面列表消失。
- 删除后刷新页面，确认不会从本地恢复。
