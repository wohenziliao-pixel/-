# 文风后三档 API 留空与用户侧隐藏模型

## 任务

1. **温柔风 / 创意风 / 重口风** 不应绑定 API（此前误填为 xAI `grok-4.3`）；仅保留文风 system 提示，生成走账号当前 API 设置。
2. 普通用户切换文风时 Toast / 状态条**不展示**具体 `openrouter/模型`；仅开发者模式可见 API 明细。

## 实现

- `EU_WRITING_STYLE_PRESETS`：后三档移除 `stChatSource` / `stModel`。
- **现代风**：OpenRouter + `deepseek/deepseek-chat-v3-0324`（不变）。
- **文学风**：仍保留 xAI + `grok-4.3`（非「后三档」）。
- `getWritingStyleApiRoute`：无 `stChatSource`+`stModel` 时不覆盖 live profile。
- `euCanShowWritingStyleApiDetails()`：`state.devModeEnabled` 为真时弹窗副文案、Toast 第二段、状态条 `title` 才带 API。
- 构建戳：`20260522-writing-style-ui-dev-only-v113`。

## 改动

- `public/eu.html`

## 自测

1. 强刷后普通用户切文风 → Toast 仅 `文风：xxx`，无 `openrouter/...`。
2. 状态条正文为 `文风：现代风`，无 `·openrouter`。
3. 温柔/创意/重口切换后发消息，Network 中 `chat_completion_source` 与未切文风时一致（账号默认）。
4. 现代风仍走 OpenRouter deepseek。
5. 开发者模式：弹窗卡片可见 API 行；Toast 可带 `· API ...`。
