# 续写立即三点、去掉「续写中」条

## 任务

用户点击续写仍无反应；不需要「续写中」文案，只要与发送时相同的**三点动画**即可确认机器在工作。

## 根因

1. 三点与 API 请求放在 `continueLastAssistant` 内第一个 `await` 之后，点击到显示之间有延迟，且易被误认为无反应。
2. `euFindDomChatItemForConvIndex` 长对话偶发对不上 DOM，未落到气泡上。
3. 「续写中」底栏条非用户所需，已移除。

## 做了什么

- 点击续写/重生成后**同步**（在任意 `await` 前）调用 `euBeginContinueUiEarly` / `euBeginRegenerateUiEarly`：原文末尾显示跳动三点。
- 去掉 `euShowGenerationStatus('续写中…')` 等底栏提示。
- DOM 定位增加按 AI 序号回退；菜单按钮增加 `addEventListener` 双保险。
- 构建戳：`20260522-continue-typing-dots-v107`（v106 起；v107 修复重新生成 `conv` 未定义）

## 自测

1. Ctrl+Shift+R，控制台 `document.documentElement.dataset.euClientBuild` 应为 `20260522-continue-typing-dots-v107`。
2. 点续写：应在**该条 AI 正文下方**立刻出现三点跳动（无「续写中」条）。
3. Console 有 `[EU] continue: click`；Network 有 generate。
