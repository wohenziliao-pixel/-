# 2026-05-02-003 会话删除误伤商城故事书硬保护

## 任务

用户反馈「我的世界移除会话会影响故事书/商城」已反复出现，需要严格兜底保护。

## 改动

在 `doDelete()`（会话删除）加入两层保护：

1. **快照校验 + 自动回滚**
   - 删除前快照 `getAcquiredSet()`
   - 删除后对比 `acquired` 是否变化
   - 若异常变化，立即 `persistAcquiredSet` 回滚，并打 warning toast 与 perf 日志（`conversation_delete_guard`）

2. **去掉会话删除后的全局视图刷新**
   - 删除会话后不再调用 `refreshLinkedViews()`
   - 仅更新 `updateWorldSubmenu()`（会话列表）
   - 避免删除会话触发商城/故事书重渲染连带异常
