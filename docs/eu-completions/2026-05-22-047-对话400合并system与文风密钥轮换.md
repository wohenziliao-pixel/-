# 对话 400：合并 system 与五档文风密钥轮换

## 任务

GLM5.1 已保存 `secret-id` 后，EU 仍提示「对话服务暂时不可用」（上游 `Bad Request` / HTTP 400）。

## 根因

1. **Custom（智谱）** 请求体含多条 `role: system` 及 `top_k` 等字段，部分 OpenAI 兼容网关返回 **400**。
2. EU 原先仅为 **custom** 轮换 `api_key_custom`；**现代风/文学风** 的 openrouter/xai 未按 profile 轮换，可能拿错全局激活密钥。

## 改动

| 路径 | 说明 |
|------|------|
| `public/eu.html` | `euPrepareMessagesForGenerate`（custom/openrouter 合并为单条 system）；`euSanitizeStPayloadForBackendSource`（custom 去掉 top_k 等）；`euActivateCustomSecretForWritingStyle` 扩展为 custom/openrouter/xai 三槽轮换；构建戳 **v128** |

## 自测

1. 硬刷新，build **`style-secret-merge-v128`**。
2. 控制台发温柔风/现代风各一条：`style secret rotate ok GLM5.1` 或 `DEEPSEEKV3 openrouter`。
3. generate **200**，无连续两条红泡。
