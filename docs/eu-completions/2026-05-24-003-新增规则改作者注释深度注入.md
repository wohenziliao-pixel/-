# 新增规则改作者注释深度注入

## 现象

用户反馈「新增规则」未生效，期望与酒馆 **作者注释（Author's Note）** 同级约束。

## 根因（核查结论）

此前 `public/eu.html` 将规则作为普通 `system` 块放在 `optionalSystem` 最前部，且：

1. 开启「字符控制」时 `getStorybookRuleSystemMessage` 被整段跳过，规则仅夹在字符控制条里，优先级表述弱。
2. Custom/OpenRouter 走 `buildTemplateSafeMessages` 时，多条 system 合并为**一条最前 system**，远离酒馆 AN 的「深度 4、贴近近期对话」位置。
3. 与 `public/单机稳定版.html` 的 `getAuthorRuleInjection` + `insertMessageByDepth` 行为不一致。

## 改动

- `insertMessageByDepth`、`buildStorybookRulesAuthorNoteMessage`、`applyStorybookRulesAtAuthorNoteDepth`
- 默认深度 `EU_STORYBOOK_RULE_AUTHOR_NOTE_DEPTH = 4`
- 规则正文前缀：`【作者注释级 · 本故事书用户规则 · 必须遵守】`
- `buildBudgetedMessages`：规则插入 **history 深度 4**，不再塞进前置 optionalSystem
- 弹窗说明已更新
- 构建戳：`20260524-storybook-rules-author-note-v145`

## 自测

1. 进入故事书对话，☰ → 新增规则，写一条明显指令（如「每句必须以「好的」开头」）。
2. 控制台：`dumpEuStorybookPromptAudit()` → `storyRulesCount > 0`，`storyRulesAuthorNotePreview` 含「作者注释级」。
3. Network → generate 请求 `messages` 中，规则应出现在**靠近末尾的历史消息附近**（非第一条 system）。
4. 硬刷新后 build 戳为 **v145**。
