# 登录不再自动进「我的世界」对话（v102）

## 任务

登录后先进入商城，约 350ms 后又被 `tryRestoreLastWorldChatSession` → `openWorldChat` 拉进「我的世界」全屏对话。  
用户要求：**登录停在商城即可**；聊天记录继续云端/本机保存，由用户从侧栏手动点开会话。

## 做了什么

- `euEnterAppLoadSessionState`：仍 `pull` 对话云、`loadConversationRuntime`，**移除** `scheduleEuResumeLastChatIfAny()`。
- `euSyncMallBrowserStateAfterLogin`：合并对话云后只 `loadConversationRuntime`，**不再**因 `convMerge === true` 自动恢复会话。
- 保留 `tryRestoreLastWorldChatSession` / `scheduleEuResumeLastChatIfAny` 供日后手动「继续上次」等入口使用。

## 改动路径

- `public/eu.html`

## 自测

1. 登录（或登出再登）→ 停留在 **商城**，不自动进入故事书对话全屏页。
2. 侧栏「我的世界」点某会话 → 仍能打开，且历史气泡仍在。
3. 关浏览器再开、从侧栏进对话 → 记录仍在（对话云 v99+）。
