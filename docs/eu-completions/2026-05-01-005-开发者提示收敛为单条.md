# 任务目标

- 将开发者模式提示从“双入口”收敛为“单入口”，避免界面重复提示。

# 实施内容

1. 移除侧边栏的开发者提示按钮：
   - 删除 `#dev-mode-entry` 相关 DOM 与样式。

2. 保留顶部红条作为唯一入口：
   - 红条点击行为改为 `handleDevModeStripClick()`。
   - 在普通页面时：点击红条进入开发者页面。
   - 在开发者页面时：点击红条退出开发者模式。

3. 红条文案改为动态：
   - `updateDevModeUi()` 根据当前是否在 `page-dev` 显示“点击进入/点击退出”。
   - `showPage()` 末尾追加 `updateDevModeUi()`，确保切页后文案同步。

# 变更文件

- `public/eu-demo.html`
- `docs/eu-completions/2026-05-01-005-开发者提示收敛为单条.md`

# 用户自测建议

- 开发者模式开启后，仅看到一条红条提示。
- 在普通页面点红条应进入开发者页；在开发者页点红条应退出开发者模式。
