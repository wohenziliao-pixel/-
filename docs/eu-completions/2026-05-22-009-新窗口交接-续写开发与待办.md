## 三、产品概念（易混，务必分清）

### 1. 字符控制（回复目标 → 字符控制）

| 项 | 说明 |
|----|------|
| 默认 | **`enabled: false`**（`EU_STORYBOOK_AUTO_CONTINUE_DEFAULT`） |
| 生效 | 仅当用户勾选 **「启用」** 并保存（按故事书 `localStorage` + 会话 `metadata.authorRule`） |
| 作用 | 注入「本条 assistant 须在 N token 内」system；收紧 `max_tokens`；发送后回复偏短可 **自动第二轮** 补写 |
| 查询 | 控制台 `getStorybookAutoContinueForGeneration()` → `enabled: true/false` |

**未勾选时，普通发消息不带字符控制。** 用户反馈「默认不生效」与代码一致。

### 2. 左下角 ☰「续写」（手动）

| 项 | 说明 |
|----|------|
| 依赖字控？ | **不依赖**；无 assistant 或非故事书页会 Toast |
| 行为 | 在**同一条**最后 AI 气泡末尾接写（`mergeContinuationReply`），不新增用户气泡 |
| v108 | `manualContinue: true` → **即使开了字控也不套用**字符控制 system / 收紧 max_tokens |
| 提示词 | `euBuildManualContinuePrompt`：结尾约 3500 字进 user 轮；history 仅 `historyBefore` |

### 3. 「重新生成」

整段替换最后一条 AI（`mode: 'replace'`），与续写 UI/数据路径分离。
