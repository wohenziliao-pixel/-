# 任务目标

- 开发者模式改为“会话内常驻”，切换页面不自动退出。
- 左侧用户区上方增加“开发者模式启动中”入口，可随时回到开发者页面。
- 仅允许点击顶部红色条后才真正退出开发者模式。
- 开发模式下普通页面保持普通用户视图，仅额外多一个开发者入口与开发者页面。

# 实施内容

1. 状态机新增：
   - 在 `state` 中增加 `devModeEnabled`。
   - `showDevMode()` 进入开发模式时置为 `true`。
   - `exitDevMode()` 仅通过红条退出，置为 `false`。

2. UI 新增：
   - 侧边栏用户信息上方增加按钮 `#dev-mode-entry`：`开发者模式启动中（点击进入）`。
   - 顶部新增红色状态条 `#dev-mode-strip`：`开发者模式启动中（点击退出）`。
   - 新增 `updateDevModeUi()`，统一控制两处显示/隐藏。

3. 行为调整：
   - 开发者页面原“退出开发者模式”按钮改为“返回普通页面（开发模式仍保持开启）”，避免误退出。
   - 登录进入后默认关闭开发模式；登出/切换账号时也会关闭开发模式。

# 用户自测建议

- 输入开发者口令进入后，随意切换首页/商城/故事书，红条与侧边入口应持续存在。
- 点击侧边“开发者模式启动中”可回到开发者页。
- 点击顶部红条后，开发者模式应真正关闭（红条与侧边入口同时消失）。
