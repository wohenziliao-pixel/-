# 灌水吧列表缩略图不显示（首楼本地图路径）

## 根因

上传成功后正文为 `![](/user/images/eu-tieba/xxx.jpg)`。服务端 `extractFirstImageUrl` 原先**只解析 Markdown 里的 `https?://` 链接**，相对路径 `/user/images/...` 永远匹配不到，导致 `GET /threads` 的 `thumbUrl` 为空，列表无缩略图；与「上传失败」无关，属**列表字段生成逻辑缺失**。

## 修复

- `src/endpoints/eu-tieba.js`：新增 `safeUserRelativeImagePath`，重写 `extractFirstImageUrl`：遍历所有 `![](...)`，依次尝试 HTTP 图与本站 `user/images` 相对路径；补充 `<img src>` 与正文中的裸 `/user/images/...` 匹配。

## 自测

重启 Node 后：带图首帖刷新列表应出现缩略图；点进详情正文 `<img>` 仍由前端 `euTiebaRichContentToHtml` 渲染（此前已支持相对路径）。
