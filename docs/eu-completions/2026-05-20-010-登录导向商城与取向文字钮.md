# 登录导向商城与商城取向文字钮（v101）

## 任务

1. **第一次登录**（登录成功进入主界面）默认打开 **商城**，不再落在首页。
2. **手机版** 显示商城「男性向 / 女性向」筛选（此前几乎看不见）。
3. 取向钮由符号 **♂ / ♀** 改为文字 **男性向 / 女性向**。

## 根因（手机不显示取向）

- `.mall-orientation-btn` 固定 **36×36px**，只放符号尚可；若改文字或字体渲染异常时内容被裁切，视觉上像「没有按钮」。
- 手机端 `.mall-filter-types` 曾 `flex-direction: column` + 标签 `width:100%`，取向行被挤到很下方；与固定方钮叠加更难发现。

## 做了什么

### 登录导向

- 登录成功：`enterApp(..., { lite: true, landing: 'mall' })` → `showPage('mall')`。
- **刷新自动恢复会话**（`tryRestoreEuAppSession`）仍为 **首页** `assistant`，避免每次重开都跳商城。

### 取向 UI

- 按钮文案：`男性向` / `女性向`。
- 样式：`width: auto` + 左右 `padding`，覆盖全局 `button{width:100%}`。
- 手机：`mall-orientation-filters` 强制横排显示；类型标签改为 **横向换行**（不再四行整宽竖排）。

## 自测

1. 新登录或登出再登 → 直接进入 **商城**，侧栏/顶栏商城高亮。
2. 刷新已登录页 → 仍进 **首页**（若需也改可再说）。
3. 手机或 `eu-mobile-preview`：筛选区可见 **男性向 / 女性向** 两枚文字钮，点击可筛选。
4. Console 构建戳含 `v101`。
