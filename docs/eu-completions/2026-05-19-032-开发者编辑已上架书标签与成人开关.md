# 开发者编辑已上架书：标签与成人开关

## 任务

线上开发者模式：首次录入时「修改内容」弹窗含标签栏与成人/全年龄切换；编辑**已上架**（仅公共商城索引、无本机 devItems 副本）的条目时，弹窗变成「修改简介与封面」，标签与成人开关消失，无法修改。

## 根因

`openEditModal` 对 `row.euCatalogPublicOnly === true` 的条目设置 `currentEditMetaOnly`，隐藏 `#modal-tags-group`、`#modal-adult-group` 与标题。保存路径 `euSavePublicMallMeta` 仅提交 `desc`/`img`。

服务端 `PUT /api/eu/mall/resource/:id` 的 `adultContent` 使用 `body.adultContent === true || prev.adultContent === true`，无法从 18+ 改回全年龄。

## 改动

- `public/eu.html`
  - 编辑弹窗对已上架公共条目与首次录入一致，始终显示标题、标签、成人开关。
  - `euSavePublicMallMeta` 支持 `title`、`tags`、`adultContent` 一并 PUT。
  - `saveDevItem` 公共条目分支写入上述字段。
  - 构建戳：`20260519-dev-edit-public-full-v84`
- `src/endpoints/eu-mall-resources.js`
  - `adultContent` 在请求体显式携带时以 `body.adultContent === true` 为准，允许改为全年龄。

## 自测

1. 开发者模式进入，对**仅商城索引**（无本机副本）的故事书点「修改」：应见标签栏与成人/全年龄。
2. 改标签与成人开关后保存，刷新列表与商城详情应一致。
3. 从 18+ 改为全年龄后，商城全年龄筛选下应能出现该书。

## 部署

需同步 `public/eu.html` 与 `src/endpoints/eu-mall-resources.js` 并重启 Node 服务。
