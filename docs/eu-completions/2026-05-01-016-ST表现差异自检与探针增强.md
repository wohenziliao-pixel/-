# 2026-05-01-016 ST 表现差异自检与探针增强

## 背景
- 用户反馈 EU 与酒馆表现差太多，希望在「逻辑无单点 bug」前提下能对齐预期、可观测。

## 改动
- `public/eu-demo.html`
  - `buildEuAlignmentProbe`：增加 `nativeChatStack`、`dialogueTurns`、system/对话估算 token、`liveMaxContext`。
  - `runEuStAlignmentSelfCheck`：合并 `getEuFeatureProbe`、最近 `context_budget` 性能日志、`EU_ST_PARITY_NOTES`（架构级差异说明）、控制台用法提示；补充探针与本地消息数不一致时的 warning。
  - 新增 `runEuStAlignmentSelfCheckAsync`：拉取 `fetchStLiveGenerationProfile` 摘要，挂到 `window.runEuStAlignmentSelfCheckAsync`。

## 控制台用法
- `runEuStAlignmentSelfCheck()`：同步快照 + `stParityNotes`。
- `await runEuStAlignmentSelfCheckAsync()`：附加酒馆 settings 侧 `max_context` / `model` 等摘要（若 API 可达）。
- 发一条消息后：`getEuAlignmentProbes().slice(-1)[0]` 看最终请求的轮次与 token 估算。
