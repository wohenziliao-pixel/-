# 连接区「保存配置」按钮

## 任务

在「连接 / 授权 / 测试消息」后增加**保存**按钮：把当前表单写入已选中的 API 连接配置存档，与「连接」分离。

## 改动

- `public/index.html`：新增 `#save_connection_profile_settings`（Save Profile / 保存配置）。
- `public/scripts/extensions/connection-manager/index.js`：
  - `saveSelectedConnectionProfileToArchive()`：读取当前表单 → `updateConnectionProfile` → 写入 `connectionSnapshot` 与 `profile.model`（已连接时）→ `saveSettingsDebounced`。
  - 未选配置时禁用按钮并提示。
  - 顶部工具栏「更新」图标与新区按钮共用同一保存逻辑。

## 建议使用方式

1. 选好 **API 连接配置** 名称。
2. 设来源、密钥、模型 → **连接** 至有效（可选测试消息）。
3. 点 **保存配置**（Save Profile）写入该条存档；**不要**依赖连接动作自动存档。

## 自测

硬刷新 → 选 Euryale 70B → 连上并选好模型 → 点「保存配置」→ 切换再切回应仍为 Euryale 模型。
