# 任务目标

- 执行“对齐酒馆链路”第 2 刀：降低世界书词条漏命中，减少剧情推进断链。

# 本次改动

在 `public/eu-demo.html` 中，把世界书词条检索从“仅本轮输入”改为“最近多轮窗口 + 本轮输入”：

1. 新增 `buildWorldInfoSearchText(userText, historyWindow)`：
   - 从当前会话中提取最近 N 条消息（默认 8，调用处使用 10）；
   - 与当前用户输入拼接为检索文本；
   - 做长度上限裁剪（1800 字符）避免注入过长。

2. 调整 `buildStorybookWorldInfoText()`：
   - 原先 `getWorldInfoMatchedEntries(entries, userText)`；
   - 现在改为 `getWorldInfoMatchedEntries(entries, buildWorldInfoSearchText(userText, 10))`。

3. 调整 `getWorldInfoMatchStats()`：
   - 统计口径同步使用多轮窗口检索文本，避免“显示命中”和“实际注入命中”口径不一致。

# 预期收益

- 当关键触发词出现在上一轮/上几轮而非本轮时，世界书词条仍可被命中；
- 角色推进更连续，减少“明明在剧情里却像丢设定”的现象。
