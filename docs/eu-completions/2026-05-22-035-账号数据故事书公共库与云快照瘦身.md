# 账号数据优化：故事书进公共库、云快照仅索引与个人资料

## 任务目标

- 任意登录用户上传的**故事书**正文写入 `data/eu-public/mall`，不再进入个人 `eu-mall-browser-state.json` 中的 devItems / heavy。
- 用户云快照仅保留：**已获取 UID 索引**、**已获取轻量 meta**、**gen 版本**、**商城隐藏列表**、**个人资料**、**本人贡献索引**（`eu_demo_upload_index_<handle>`）。
- **对话三键**继续只走 `GET/POST /api/eu/browser-state/conversations`；贴吧仍用独立 `data/eu-tieba-board.json`。

## 已完成内容

### 服务端

- `src/endpoints/eu-mall-resources.js`
  - `POST /api/eu/mall/contribute`：登录即可贡献故事书（`source: contributed`）。
  - `PUT /api/eu/mall/contribute/:id`：贡献者本人或 mall.publisher / super.admin 可改元数据。
  - `GET /api/eu/mall/capabilities` 增加 `canContribute`。
- `src/endpoints/eu-browser-state.js`
  - 白名单移除 `eu_demo_dev_*` / heavy / overflow；新增 `eu_demo_upload_index_<handle>`、`eu_demo_acquired_gen_<handle>`。
  - 每次 `POST /api/eu/browser-state` 合并后 **purge** 已废弃的 dev/heavy 键。

### 前端 `public/eu.html`（构建戳 `20260522-account-data-storybook-public-v118`）

- `euMallBrowserStateLsKeys` 仅个人轻量键；`euPushMallBrowserStateNow` 不再上传 heavy / dev 分片。
- 登录拉取不再从云端恢复 `eu_demo_dev_heavy`。
- `euContributeMallResourceFromDevItem` + `euPublishOrContributeMallResourceFromDevItem`：批量/单条保存故事书时写入公共库并登记已获取 + 上传索引。
- `euSavePublicMallMeta`：非管理员且为本人贡献时走 `PUT /contribute/:id`。

## 需要用户自测

1. 重启 node 后硬刷新 `eu.html`，Console 构建戳为 **v118**。
2. 用**无 mall.publisher** 的普通账号：开发者模式批量保存一本故事书 → 检查 `data/eu-public/mall/resources/` 出现新 JSON；`data/<handle>/eu-mall-browser-state.json` **不应**再增大 dev/heavy 键。
3. 同一账号换浏览器登录：已获取列表与资料能拉回；故事书正文从商城/预览接口读取。
4. 对话与贴吧：续聊仍走对话云接口；删帖权限与改造前一致。
5. 有 **mall.publisher** 的账号：故事书仍可通过原 `POST /resource` 上架（`source: public`），行为与贡献路径并存。
