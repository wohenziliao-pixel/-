# 任务目标

- 在“故事书”页面提供直接“移出我的世界”入口，避免用户必须回到开发者列表操作。
- 保持与既有用户侧权限模型一致：仅清理当前用户数据，不删除商城公用资源。

# 实施内容

1. 在 `public/eu-demo.html` 中新增通用方法 `removeMallItemFromMyWorld(uid, opts)`：
   - 统一处理“移出我的世界”逻辑；
   - 清理当前用户 `acquired` 标记；
   - 对故事书类型联动清理当前用户会话、规则缓存，并请求后端删除对应聊天文件；
   - 保持商城公用资源不被删除。

2. 改造原 `deleteDevItem(id)`：
   - 改为调用 `removeMallItemFromMyWorld()`，复用同一逻辑，避免两套行为分叉。

3. 在故事书卡片 UI 增加按钮：
   - `renderStorybooks()` 卡片底部新增“移出我的世界”按钮；
   - 点击按钮不会触发“打开故事书对话”（已 `stopPropagation`）。

# 变更文件

# 用户自测建议

- 在故事书页点击“移出我的世界”后确认：
  - 故事书从“我的故事书”列表消失；
  - 对应会话记录被清掉；
  - 该书规则不再残留；
  - 商城公用商品本体仍存在且可重新获取。
