# 续写 / 重新生成：生成中动画与流式体感

## 任务

用户反馈：☰ 菜单 **续写**、**重新生成** 点击后缺少体感（无三点动画、无流式输出），应与 **发送消息** 时一致。

## 做了什么

`public/eu.html`：

1. 新增共用 UI 辅助：
   - `euMountAssistantGenerationBubble`：在最后一条 AI 气泡上显示 **三点 typing**
   - `euStreamGenerateIntoBubble`：优先 **流式** `requestAiReplyStream`，失败则非流式 + `renderAssistantPseudoStream`
   - `euFinalizeAssistantBubble` / `euShowGenerationErrorInBubble`：收尾与错误展示
2. `EUAdapter.regenerateLastAssistant`：生成前挂载动画 → 流式/伪流式 → 原地更新气泡（**不再** `openWorldChat` 整页重绘）
3. `EUAdapter.continueLastAssistant`：同上；合并续写后刷新同一条气泡
4. 构建戳：`20260522-regen-continue-typing-v103`

未改酒馆 `index.html` / `script.js`。

## 用户自测

1. **Ctrl+Shift+R** 强刷 `eu.html`，控制台构建戳含 `v103`
2. 故事书对话发一条消息后，点 ☰ → **重新生成**：最后一条 AI 气泡应先 **三点**，再 **流式/打字机** 出新正文
3. 点 ☰ → **续写**：同上，成功后同一条气泡变长
4. 失败时气泡或 Toast 有明确错误，而非长时间无反应
