# 桌面角色卡 JSON 与 PNG 合成工具

## 任务

独立桌面小工具：选 JSON + PNG，一键合成酒馆可读的 PNG 角色卡（内嵌元数据）。

## 实现

- `tools/eu-card-png-composer/`：本地 Express + 静态页；`POST /api/compose` 调用 `src/character-card-parser.js` 的 `write()`（与 ST 一致：`chara` base64 + 可选 `ccv3`）。
- `一键启动-角色卡合成.bat`：启动服务并打开浏览器。
- `创建桌面快捷方式.bat`：复制启动器到桌面。

## 自测

1. 双击桌面快捷方式 → 浏览器打开合成页。
2. 导入任意角色 JSON + PNG → 合成下载。
3. 在 SillyTavern「导入角色卡」选该 PNG，应能读出 JSON。
