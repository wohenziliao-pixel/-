# 灌水开发者删帖：查询参数与 403 说明

## 问题

用户已开 EU 开发者模式，删帖仍提示需管理员 / 无权限。常见原因：① 服务端未收到 `euTiebaDev`（反代丢弃 DELETE JSON body、或 Node 未重启仍为旧接口）；② DELETE 未带上酒馆会话 Cookie，服务端 `req.user` 为空。

## 改动

- `src/endpoints/eu-tieba.js`：`readEuTiebaDevClientFlag` 增加查询参数 `euTiebaDev=1|true|yes`；403 使用 `tiebaDeleteForbiddenDetail` 区分配置关闭、无会话、无开发者标记。
- `public/eu-demo.html`：非版主开发者删帖在 DELETE URL 追加 `?euTiebaDev=1`（与 JSON 体双通道）；构建戳 `20260512-066`。

## 用户自测

硬刷新 EU 页后批量删帖；若仍 403，读 Toast 内完整说明；并重启 SillyTavern 进程、检查反代对 DELETE 的 Cookie 转发。
