# eu.html 黑屏：GLM5.1 对象键语法错误

## 任务

用户强刷 `eu.html` 后整页黑屏，控制台 `Uncaught SyntaxError: Unexpected number (eu.html:6012:7)`，连带 `hideModal is not defined`。

## 根因

v126 新增 `EU_CUSTOM_SECRET_LABEL_HINTS` 时写了未加引号的键名 `GLM5.1:`。JavaScript 会解析成 `GLM5` + `.1`（非法数字字面量），导致**整段脚本无法执行**，页面无法初始化。

## 改动

| 路径 | 说明 |
|------|------|
| `public/eu.html` | 改为 `'GLM5.1': [...]`；构建戳 `20260522-glm-hints-syntax-fix-v127` |

## 自测

1. 硬刷新 `eu.html`，无 SyntaxError，页面正常显示登录/故事书。
2. 控制台 build 为 **v127**。
3. 温柔风发消息，`custom secret rotate ok GLM5.1`（用户已保存 secret-id）。
