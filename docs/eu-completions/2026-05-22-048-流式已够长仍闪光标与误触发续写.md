# 流式已够长仍闪光标与误触发续写

## 任务

用户反馈：正文已经够长，但气泡末尾 `|` 光标一直闪，标题区无结束 token 统计，界面像卡在「ST 生成中」。

## 根因

1. **流式结束后**仍保留 `.streaming-cursor`，且 token 角标要等整段 `try`（含自动续写、后处理）跑完才更新。
2. **自动续写误判**：末行短对白如 `“跑。”` 以引号结尾，`looksReplyIncomplete` 认为未完结，在 `finish_reason=length` 且正文已很长时仍发起第二轮 `requestAiReply`，界面长时间停在「流式光标 + 后台续写」。

## 改动

| 路径 | 说明 |
|------|------|
| `public/eu.html` | `looksReplyIncomplete` 识别 `。\"` 等；`length` 且正文已够长不再续写；流式结束即去掉光标，续写时改三点动画；续写超时跳过；构建戳 **v129** |

## 自测

1. 硬刷新 **v129**，发一条长回复故事书。
2. 模型在 `“跑。”` 等对白处停下时：光标应消失，角色名旁出现 **≈NT**。
3. 不应长时间只闪 `|` 无 token；若开启自动续写且确实偏短，气泡末尾短暂三点后合并或超时结束。
