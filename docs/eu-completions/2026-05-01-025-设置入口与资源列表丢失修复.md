# 2026-05-01-025 设置入口与资源列表丢失修复

## 问题

1. **设置页**已存在但侧边栏/顶栏无入口，用户找不到 max_tokens 覆盖等选项。
2. **故事书/商城**中某故事书消失，但「我的世界」仍有会话：疑与移除会话无关，而可能与 **导入/加载后** 数据不一致有关。

## 根因（2）

- **分仓 localStorage**（`eu_demo_dev_items_storybook` 等）与 **`eu_demo_dev_items` 统一键** 若不同步（例如某一类被写成空数组），启动时只合并分仓会 **丢掉** 仅在统一键中的故事书；会话仍留在 `conversationStore`，表现为列表空、侧栏仍有。
- **`mapDevItemToMallItem`** 曾用 `item.id || Date.now()` 生成 `imported-*` uid；缺 `id` 时 **每次调用** 得到新 uid，与 `acquired` 集合不对齐，列表与「已获取」异常。

## 改动

- 侧边栏增加 **「设置」**；用户下拉增加 **「设置（max_tokens 等）」**；原「切换账号」改为显式 `switchTab('login')`（行为仍为回登录页）。
- 新增 `openEuSettingsFromTopbar()`（未登录提示先登录）。
- **`euStableDevItemId` + `normalizeDevItemShape`**：无 id 时生成稳定 `eu_*` id；**`mapDevItemToMallItem`** 仅用规范化后的 id 拼 uid。
- **加载 devItems**：在存在分仓时 **再从 `eu_demo_dev_items` 合并** 分仓中缺失的条目（按 `id` 或 `type+title` 去重），再 `persistDevItems` 写回。

## 路径

- `public/eu-demo.html`（`EU_CLIENT_BUILD_STAMP` → `20260501-025`）

## 自测

1. 登录后侧边栏可见「设置」，可改 max_tokens 覆盖并保存。  
2. 模拟：分仓 storybook 为 `[]`、统一键仍有故事书 → 刷新后故事书应回到商城/故事书列表（需重新保存一次分仓）。  
3. 若仍缺：检查 **全年龄模式** 是否隐藏了 `adultContent` 的商城卡片（故事书页不受该过滤，但若 acquired 与 uid 仍错位需重新在商城获取一次）。
