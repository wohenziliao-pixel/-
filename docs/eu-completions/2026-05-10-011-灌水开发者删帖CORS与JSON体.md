# 灌水开发者删帖：CORS 与 JSON 体

## 问题

批量/单帖开发者删帖全部失败（如「已删除 0 个，失败 N 个」）。常见原因：`config.yaml` 中 `cors.allowedHeaders` 仅包含 `Content-Type`、`X-CSRF-Token` 时，跨域预检不允许自定义头 `X-EU-Tieba-Dev`，浏览器拦截 DELETE。

## 改动

- `src/endpoints/eu-tieba.js`：`readEuTiebaDevClientFlag` 同时接受请求头 `X-EU-Tieba-Dev: 1` 与 JSON 体 `euTiebaDev: true`（或 `1`）；`canDeleteTiebaContent` 使用该标识。
- `public/eu-demo.html`：非版主开发者删帖改为在 DELETE 请求体中附加 `euTiebaDev: true`（`euTiebaDeleteBody`），不再依赖自定义请求头；批量失败 Toast 附带首条错误摘要；构建戳 `20260512-065`。

## 用户自测

在 Eureka 等跨端口访问 EU、且 CORS 未放行 `X-EU-Tieba-Dev` 的配置下，开发者模式勾选批量删帖应成功。
