# openai.js 重复导出导致刷新黑屏修复

## 问题

刷新后页面黑屏，控制台：`Uncaught SyntaxError: Duplicate export of 'reconnectOpenAi'`（`openai.js`）。

## 原因

`reconnectOpenAi`、`getOpenAIConnectionDefaults`、`setChatCompletionSourceQuiet` 同时在文件顶部 `export { ... }` 与 `export function` 中导出，模块加载失败。

## 改动

`public/scripts/openai.js`：从顶部 `export { }` 块中移除上述三项，仅保留 `export function` 声明处导出。

## 自测

硬刷新 `http://127.0.0.1:8000/index.html`，控制台无该 SyntaxError，API 设置页可正常打开。
