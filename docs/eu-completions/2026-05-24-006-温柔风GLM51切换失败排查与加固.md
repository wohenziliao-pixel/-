# 温柔风 GLM5.1 切换失败排查与加固

## 任务

用户反馈五档文风中仅 **温柔风** 不可用（发消息「对话服务暂时不可用」）；状态条已显示「文风：温柔风」。

## 根因（为何只有温柔风）

| 文风 | 路由 | 说明 |
|------|------|------|
| 现代/文学 | OpenRouter | 共用 `api_key_openrouter` |
| 创意 | xAI | 共用 `api_key_xai` |
| 重口 | custom + **VENICE** | 另一套 custom 密钥 |
| **温柔** | custom + **GLM5.1** | 智谱 `bigmodel.cn`，须单独 `secret-id` 轮换 |

常见问题：

1. 用户目录（如 `mico`）**未同步**站长 `connectionManager`（缺 GLM5.1 或 `exclude` 含 `secret-id`）。
2. 切换文风时 `euActivateCustomSecretForWritingStyle` 曾 **fire-and-forget**，发消息时仍用 Venice 密钥打智谱 → 401/400。
3. 线上 `eu.html` 构建戳过旧（如 v142），缺少 v125+ 密钥解析与合并 system 修复。

本机 `node tools/eu-audit-writing-style-apis.mjs wohenziliao` 五档均为 OK，说明预设与站长配置正确，**问题在特定用户数据或部署版本**。

## 改动

- `public/eu.html`（`20260524-gentle-glm51-ready-v148`）
  - 新增 `euEnsureWritingStyleReady`；`selectWritingStyle` 切换时 **await** 刷新 CM + 轮换密钥，失败即 Toast（温柔风专用文案）。
  - `validateEuWritingStyleGenerationRoute`：缺 GLM5.1 profile / secret 时温柔风专用提示。
