# 移除乱入/群聊与严格对齐下减少二次模型干扰

## 任务目标

在「改用线上大模型、减少旧 EU 层干扰模型思考」的前提下，删除乱入角色与群聊相关能力与代码路径；在 `EU_STRICT_ST_ALIGNMENT === true` 时不再做「空回复再生成」「非中文改写」等二次请求，并跳过对历史的毒短句清洗，尽量保持 ST 主链路与单角色会话稳定。

## 已做改动

- `public/eu-demo.html`
  - 新增 `stripLegacyEuMultiCharacterMetadata`：在 `migrateLegacyHistoriesIntoConversationStore` 遍历会话时删除 `metadata.crossoverRoles`、`metadata.groupChat`，并清理 `authorRule` 内已废弃的 `replyMaxTokens*` 字段。
  - 移除 `EU_RUNTIME.visibility.showGroupEntry`、`world-group-btn` 绑定、`/group` 与 `/groupmode` 斜杠命令及相关群聊/乱入工具函数；发送路径固定为当前故事角色单路 `promptText = 用户输入`。
  - `regenerateDialogueOnlyIfNeeded` / `rewriteReplyToChineseIfNeeded`：在严格对齐模式下直接返回已 sanitize 的正文，不再发起第二次补生成。
  - `scrubRpHistoryForToxicMicroReplies`：在严格对齐模式下返回历史浅拷贝，不再删改 assistant 短句与合并 user。
  - 客户端构建号：`EU_CLIENT_BUILD_STAMP` → `20260503-033`。

## 用户自测建议

1. 硬刷新 `eu-demo.html` 后控制台确认 `client build` 为 `20260503-033`。
2. 世界聊天发数轮：确认无群聊/乱入相关 UI 与命令；回复不应再因「非中文」等触发隐式第二次全文改写（严格模式下）。
