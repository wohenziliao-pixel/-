1. 改底栏连接态 → **整页黑屏**（`eventSource` 重复 import，`RossAscends-mods.js`）→ `2026-05-21-015`
2. 修发送/遮罩 → **按钮全死** → 回退 `script.js` 等 → `2026-05-21-031`
3. 为消黑屏 **整包 checkout `public/`** → 连带撤掉 xAI tokenizers 修复 → **Token 计数红条**、发送中断 → `2026-05-22-001`、`2026-05-22-002`

### 2.2 根因要点

| 现象 | 根因 | 处理 |
|------|------|------|
| 黑屏、无 Initializing | ES 模块 SyntaxError，`script.js` 链未执行 | 仅保留 `events.js` 一处 `eventSource` import |
| 灰屏 preloader 不消失 | 同上或缓存旧 `script.js` | Ctrl+Shift+R；必要时重启 `node server.js` |
| Token 计数红条 | xAI 走 gpt-3.5 tiktoken；`/api/tokenizers/.../count` 失败无 catch | `tokenizers.js`：XAI→deepseek 近似 + ajax 失败 guesstimate |
| 输入不消失、用户句不进聊天气泡 | `Generate()` 深处才 `addOneMessage`；回车与按钮路径不一致 | 窗口内曾改 `commitUserMessageFromTextarea`，**已随 031 回退**；EU 侧不依赖此修复 |
| 遮罩挡点击 | `forceCloseLoaderOverlay` 等实验改动 | **已回退** |

## 4. 窗口 C：EU 续写 / 重新生成（009 继承 + v109）

### 4.1 概念（必分清）

| 类型 | 入口 | 默认 |
|------|------|------|
| **字符控制**（自动续写） | ☰ → 新增规则 → 启用 + 目标 Token | **关** |
| **手动续写** | 左下角 ☰ → **续写** | **不依赖**字控 |
| **重新生成** | ☰ → 重新生成 | 整段替换最后 AI |

手动续写：`manualContinue: true` → 不注入字控 system、不收紧 `max_tokens`；结尾 ~3500 字进 **user** 轮；history 不含重复的最后 assistant。

### 4.2 构建戳演进（本会话）

| 戳 | 内容 |
|----|------|
| v103–v105 | 三点、流式进气泡 |
| v106–v107 | 点击同步三点、去「续写中」条 |
| v108 | 手动续写 prompt、字控剥离、history 不重复 |
| **v109** | SSE 尾包 flush、手动续写减 system、流式 rawChunkDisplay、预设 allowStale |

### 4.3 关键代码（`public/eu.html`，行号约）

```
handleWorldChatContinue / EUAdapter.continueLastAssistant
euBeginContinueUiEarly / euStreamContinueIntoBubble
euBuildManualContinuePrompt / buildBudgetedMessages(manualContinue)
requestAiReplyStream / euConsumeSseLine / euFlushSseBuffer
mergeContinuationReply / EU_CLIENT_BUILD_STAMP
```

### 4.4 续写卡住排查顺序

1. Console：`continue: click` → `request` → **`chunk`** → `done`
2. Network：`POST .../chat-completions/generate` 是否结束；pending 查 API/密钥/终端日志
3. 无 `chunk`：SSE 尾包（v109）、`extractStreamingDelta` 空 → 非流式 fallback
4. 有 chunk 气泡不长：`mergeContinuationReply` 剥空 → 应提示「无有效新增」
5. `browser-state large` → 先瘦身再测
6. `worldMessageActionBusy` 未释放 → 刷新页

## 5. 跨窗口共用注意事项

### 5.1 部署 / 缓存

- 改 `src/endpoints/*` → **必须重启** Node；只改 `eu.html` → 强刷即可
- 线上验证：`grep EU_CLIENT_BUILD_STAMP public/eu.html`
- 勿用本机整包 `data/` 覆盖线上用户数据；商城仅 SFTP `data/eu-public/mall/`

### 5.2 API / 生成

- EU 生成：`/api/backends/chat-completions/generate`（`requestAiReply` / `requestAiReplyStream`）
- 预设：`fetchStLiveGenerationProfile` ← `/api/settings/get`（60s 缓存；续写可 `allowStale`）
- xAI 模型名须在预设里为 Grok 系，勿留 OpenAI 名（`assertValidXaiModelOrThrow`）
- `error: true` 多为上游/密钥；看 **运行 ST 的终端日志**

### 5.3 内存 / OOM

- 商城分页 10 条、禁全量合并、轻量登录——见 `2026-05-16-*` 系列
- 开发者列表勿全量水合大 JSON
